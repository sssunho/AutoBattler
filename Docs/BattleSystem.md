# 전투 시스템 명세 및 구현 현황

- 기준일: 2026-10-18
- 기획 개정일: 2026-11-07 — 궁수의 특수화살 제작, 정령궁수와 지면·공기 환경효과 반영
- 대상: 현재 턴제 전투 시스템
- 문서 상태: 현재 구현과 기획 확정·미구현 규칙을 구분하여 관리

## 1. 목적과 관리 기준

이 문서는 전투 시스템의 현재 동작, 확정한 전투 기획, 앞으로 결정할 문제를 관리한다. 탐험, 시나리오·이벤트, 캐릭터 성장과 자산 제작은 직접적인 전투 연결 규칙이 필요한 경우에만 다룬다.

레벨 성장의 기본 구조는 [Plan.md](Plan.md), 파티 공유 성장과 용병별 전문화·선택 보상은 [MercenarySystem.md](MercenarySystem.md)를 따른다. 도적 전문화는 4.7절, 수호자·개척자는 4.8절, 도적·궁수의 Lv1 액티브는 4.9절의 확정 범위를 따른다. 암살자 Lv5 액티브의 기존안은 철회했고 대체 효과는 미정이다. 방향별 물리 피해 차단은 수호자 Lv2 패시브로 정리한다. 장비 효과는 4.10절, 우선권·기회 공격·경계사격의 공통 이동 반응은 4.11절, 기사·기어스는 4.12절, 궁수의 준비 능력·정령궁수는 4.13절, 환경효과는 4.14절의 기획이다. 코드·에셋 반영 완료를 뜻하지 않으며 현재 구현은 3절과 구분한다. Lv3 공용 특성·Lv4 직업 스킬 구분과 공통 치명타 규칙은 유지하며 정령궁수의 다속성 기본 공격에는 명시한 예외를 적용한다.

기존 `combat_design_prototype_v0_1.md`는 첫 프로토타입의 목표를 기록한 문서로 보관하며 갱신하지 않는다. 이후 합의한 취소와 View 비활성화 정책은 이 문서에 반영한다.

| 상태 | 의미 |
|---|---|
| 구현 완료 | 현재 코드에 구현되어 있다. 실행 검증의 범위와 시점은 7절에서 별도로 확인한다. |
| 기획 확정·미구현 | 동작과 범위를 합의했으나 현재 코드에 반영되지 않았다. 구현 순서와 시점은 별도로 정한다. |
| 결정 필요 | 도입 여부 또는 동작을 정해야 한다. 구현 약속이나 우선순위를 뜻하지 않는다. |

확정된 변경은 기대 동작, 실패·취소 조건, 자원 소비 시점, 완료 판단 기준을 기록한다. 구현 후에는 현재 명세에 통합하고 검증 기록을 갱신한다. 단순 아이디어를 기획 확정·미구현으로 분류하지 않는다.

## 2. 범위와 기본 원칙

- 전장은 높낮이를 전술 규칙으로 사용하지 않는 단일 층의 헥스 맵이다.
- 아군과 적이 함께 참여하는 라운드 기반 개별 턴을 사용한다. 한 번에 하나의 행동만 진행한다.
- AP와 이동력은 독립적인 자원이다. 한 턴 안에서 이동과 기본 공격을 교차할 수 있다.
- 순수 C# 로직이 논리 좌표, 점유, 자원, 피해, 턴을 관리한다. Unity View는 모델과 애니메이션을 표시한다.
- 로직은 `deltaTime`을 받지 않는다. 이동은 hex별 step으로 처리하고, 필요하면 다음 step 발행을 대기한다.
- 실제 게임의 `BattleRunner`는 정상적인 연출 완료를 기다려 로직의 완료 함수를 호출한다. 로직이 Unity를 참조하지 않는다는 것과 모든 행동을 즉시 완료한다는 것은 별개의 사항이다.
- 이미 발행한 이동·공격 step은 사용자 취소로 되돌리지 않는다. 취소 대상은 아직 발행하지 않은 경로와 공격 예약이다. 유닛 제거와 시스템 종료의 수명 처리는 3.7절을 따른다.
- 이동·공격 step ID는 사용하지 않는다. 유닛을 식별하는 ID는 유지한다.

기존 오토배틀러 코드는 `Assets/Scripts/AutoBattlerCombat`, `Assets/Scripts/AutoBattlerCombatView`에 분리되어 있으며 이 문서의 대상에서 제외한다. 현재 턴제 코드는 `Combat`, `CombatView`를 사용하고, 헥스 공통 어셈블리는 `RaggedBanner.HexGrid`, `RaggedBanner.HexGridView`다.

## 3. 현재 구현 명세 — 구현 완료

### 3.1. 전장과 초기 등록

- `BattleBoard`가 논리 `HexMap`과 유닛 목록을 소유하며, 좌표와 타일 점유를 함께 변경한다.
- 한 hex에는 한 유닛만 존재한다. 이동은 유효한 인접 hex로만 가능하며, 아군·적 모두 다른 유닛이 점유한 hex를 통과하거나 목적지로 사용할 수 없다.
- 현재 경로 탐색은 각 hex의 이동 비용을 1로 취급하는 BFS다. 지형별 비용, 높낮이, 별도의 지형 장애물 규칙은 없다. 씬의 지형이나 Collider가 자동으로 논리 장애물이 되지는 않는다.
- 초기 씬 배치 유닛은 View의 월드 위치에서 가장 가까운 맵 내 hex 중심을 찾아 등록하고 그 위치로 맞춘다. 시작점 탐색에 최대 거리 제한은 없다.
- 가장 가까운 hex가 점유되어 있으면 등록을 거부한다. 다른 빈 hex로 자동 재배치하지 않는다.
- 맵 누락·잘못된 크기·유효하지 않은 hex 크기·시작 좌표 탐색 실패·중복 배치·잘못된 View 설정은 초기화 오류로 처리하고 Runner를 중단한다.
- 초기 등록과 설정 검증을 마친 뒤 전투를 시작한다. 등록은 `Preparing` 상태에서만 가능하며 전투 도중 합류는 지원하지 않는다.
- 아군 인원 상한은 설정값으로 검사한다. 현재 별도의 적 인원 상한은 없다.
- 실행 중 맵의 크기 또는 hex 크기가 변경되거나 맵이 유효하지 않게 되면 Runner를 중단하고 연결을 정리한다.

### 3.2. 설정값

`BattleRunner`의 Inspector 설정을 초기화 시 불변 `BattleRules`로 확정한다. 실행 중 Inspector 값을 바꿔도 이미 생성한 전투 규칙에는 소급 적용하지 않는다.

| 항목 | 코드 기본값 | 저장된 Mine 씬의 값 |
|---|---:|---:|
| 최대 아군 인원 | 4 | 4 |
| 시작 AP | 4 | 4 |
| 최대 AP | 8 | 8 |
| 자신의 턴당 AP 부여량 | 4 | 4 |
| 기본 공격 AP 비용 | 2 | 2 |
| 자신의 턴당 이동력 | 2 | 3 |
| 초기 HP | 10 | 5 |
| 기본 공격 피해 | 3 | 3 |

씬 값은 2026-10-17 저장 파일 기준의 테스트 설정이며 최종 밸런스가 아니다. 해당 씬에는 아군 3명과 적 2명이 초기 등록되어 있다. 기본 공격 사거리는 현재 코드에서 1로 고정하며 Inspector 설정 항목이 아니다.

최대 아군 인원·최대 AP·공격 비용·초기 HP·피해는 양수여야 한다. 시작 AP는 0 이상 최대 AP 이하, 턴당 AP 부여량과 이동력은 0 이상이어야 한다. 유효하지 않은 규칙은 전투 생성 시 거부한다.

### 3.3. 라운드, 턴, 자원

- 각 라운드 시작에 생존 유닛 전체를 무작위로 섞는다. 아군·적을 구분하여 번갈아 배치하지 않는다.
- 살아 있는 유닛은 라운드당 한 번 턴을 갖는다. 자신의 차례 전에 제거된 유닛은 건너뛰며 다음 라운드 목록에서도 제외한다.
- 라운드마다 순서를 다시 정하므로 이전 라운드 마지막 유닛이 다음 라운드 첫 유닛이 될 수 있다.
- 로직 생성자는 재현용 난수 seed를 받을 수 있다. 현재 Runner에는 seed를 편집하는 Inspector 항목이 없다.
- 각 유닛의 첫 턴에는 시작 AP만 사용한다. 턴당 AP를 중복 지급하지 않는다.
- 두 번째 자신의 턴부터 `min(이월 AP + 턴당 AP, 최대 AP)`를 적용한다.
- 이동력은 자신의 턴 시작마다 설정값으로 재설정하며 이월하지 않는다. 일반 이동은 AP를 쓰지 않는다.
- 현재 턴의 유닛만 행동할 수 있다. 행동 중에는 새 이동·공격과 턴 종료를 거부한다.
- 플레이어 턴은 자원을 모두 사용해도 자동 종료하지 않는다. 자원이 남아 있어도 수동 종료할 수 있다.

| 전투 상태 | 동작 |
|---|---|
| `Preparing` | 초기 유닛 등록을 받는다. 현재 턴은 없다. |
| `Running` | 턴과 행동을 진행한다. |
| `Waiting` | 어느 한 진영에 생존자가 없거나 초기 참여자가 부족하다. 새 행동과 턴 종료, 라운드 생성과 AP 갱신을 멈춘다. |

`Waiting`은 승리·패배 판정이 아니다. 이 상태에서 합류나 전투 재개는 지원하지 않는다. 외부 유닛 제거로 대기에 들어갈 때 이미 발행된 step이 남아 있으면 해당 step의 정리까지 진행할 수 있다.

### 3.4. 이동과 대기

1. 빈 hex를 목표로 지정하면 현재 논리 좌표에서 최단 경로를 찾는다.
2. 경로 전체가 남은 이동력 이내일 때만 명령을 접수한다. 범위 밖 목적지로 가능한 만큼만 이동하는 플레이어 명령은 없다.
3. `TryBeginMovementStep()`이 다음 한 hex의 좌표·점유를 변경하고 이동력 1을 차감한 뒤 step을 반환한다.
4. View가 이전 위치에서 해당 hex 중심까지 이동 연출을 수행한다. 이동 중에는 Walk, 정지 상태에서는 Idle을 사용한다.
5. Runner가 `TryCompleteMovementStep()`을 호출하면 다음 step을 시작할 수 있다. 경로가 끝나면 행동을 해제하거나 예약된 공격으로 넘어간다.

화면상의 위치가 이동 중이어도 논리 좌표와 점유는 해당 step의 목적지에 있다. 한 프레임에 남은 연출 시간이 충분하면 여러 step을 순차 처리할 수 있지만, 각 step의 발행과 완료 순서는 유지한다.

이동 일시정지·재개 API가 있다. 일시정지는 이미 발행된 step의 완료를 막지 않고 다음 step 발행을 막는다. 재개해도 이전 step의 완료 대기를 건너뛰지 않는다. 현재 일시정지·재개에 할당한 플레이어 키나 UI는 없다.

### 3.5. 기본 공격, 피해, 사망

기본 공격은 인접한 적 한 명을 대상으로 한다. 자신·같은 진영·제거된 유닛은 공격 대상이 될 수 없다.

| 공격 명령 시 조건 | 처리 |
|---|---|
| 인접하고 AP가 충분함 | `ReadyToAttack`으로 전환한다. |
| 인접하지 않지만 빈 인접 hex까지 전체 경로와 이동력이 충분함 | 최단 경로로 접근한 뒤 공격한다. |
| 접근 경로가 없거나 이동력이 부족함 | 명령을 거부한다. 이동력과 AP를 소비하지 않는다. |
| AP가 부족함 | 접근도 시작하지 않는다. 일반 이동은 별도로 명령할 수 있다. |

접근과 공격은 하나의 행동으로 잠근다. 접근 중 대상이 제거되면 남은 경로와 공격 예약을 버리며, 다른 대상으로 바꾸거나 경로를 다시 찾지 않는다.

공격 실행 순서는 다음과 같다.

1. `TryBeginAttack()`에서 대상·진영·사거리·AP를 다시 검사한다.
2. AP를 차감하고 공격 step을 발행하며 `Attacking` 상태가 된다.
3. View가 대상을 향하고 Attack을 재생한다. 정상 연출은 완료까지 기다린다.
4. `TryCompleteAttack()`에서 대상과 사거리를 다시 검사하고 피해를 한 번 적용한다.
5. 행동 잠금을 해제한다. 사망 시 논리 유닛과 점유를 제거하고 Runner가 View를 해제한다.

- AP는 공격 명령 접수나 접근 시작 시점이 아니라 공격 step 발행 시 차감한다.
- HP는 0 아래로 내려가지 않으며 실제 감소량은 남은 HP 이하다. HP가 0이면 제거한다.
- 공격 완료 후에도 AP와 유효한 대상이 있으면 다시 공격할 수 있다. 별도의 턴당 공격 횟수 제한은 없다.
- 마지막 상대를 처치하면 피해·사망·행동 완료를 처리한 뒤 `Waiting`으로 전환한다.
- 실제 타격 프레임의 Animation Event에 피해를 연결하지 않는다. 정상 상태에서는 Attack 애니메이션의 완료를 기준으로 한다.

행동 상태는 `None`, `Moving`, `ReadyToAttack`, `Attacking`이다. `Attacking` 자체가 공격 step의 완료 대기를 뜻한다. 이동은 별도의 이동 완료 대기 상태로 다음 발행을 제한한다.

완료 함수는 Runner가 현재 대기 중인 step에 대해 순서대로 호출하는 계약이다. 완료 후 다음 step이 발행되지 않은 상태의 중복 완료는 거부한다. step ID로 과거 요청을 식별하는 기능은 없으며, 새 step 발행 뒤 도착하는 임의의 오래된 비동기 완료 콜백을 구분하는 방식은 지원하지 않는다.

### 3.6. 취소

플레이어는 자신의 턴에 UI 밖에서 우클릭하여 `CancelAction()`을 요청한다.

| 취소 시점 | 결과 |
|---|---|
| 이동 step 발행 전 또는 step 사이 | 남은 경로와 공격 예약을 지우고 행동을 끝낸다. |
| 이동 step의 연출 중 | 현재 step은 완료하고 남은 경로와 공격 예약만 지운다. 완료까지 새 명령과 턴 종료는 거부한다. |
| 공격 준비 상태, 공격 step 발행 전 | 공격 예약을 취소한다. 공격 AP는 소비하지 않는다. |
| 공격 step 발행 후 | 취소 요청을 무시한다. 연출과 완료 처리를 유지하며 AP를 환불하지 않는다. |
| 진행 중인 행동 없음 | 추가 효과가 없다. |

취소는 이미 확정된 위치·이동력·AP를 되돌리는 기능이 아니다. 이동 중 취소할 때 현재 step의 도착 위치로 즉시 순간이동시키지 않고, 정상 View에서는 해당 step 연출을 마친다.

### 3.7. View, 유닛 제거, Runner의 수명

View 비활성화와 논리 유닛 제거는 서로 다른 동작이다. 현재 일반 이동과 접근 공격은 연출 불가 시의 처리도 다르다.

| 상황 | 현재 처리 |
|---|---|
| 등록된 View 컴포넌트 또는 GameObject 비활성화 | 논리 유닛·점유·턴 자격은 유지한다. View 내부 연출 상태를 정리하고 논리 위치로 맞춘다. |
| View 재활성화 | 논리 위치에 맞추고 Idle로 복귀한다. |
| 일반 이동 명령 시 View 준비 불가 | Runner가 이동 명령을 거부한다. |
| 일반 이동 중 View 비활성화·연출 불가 | 이미 발행된 step은 완료 처리하고 남은 경로를 중단한다. 확정 위치와 소비한 이동력은 유지한다. |
| 접근 공격 중 공격자 View의 연출 불가 | 남은 접근과 공격 로직을 진행한다. 표시할 수 없는 연출은 생략한다. |
| 공격 연출 시작·완료 확인 불가 또는 진행 중 공격자 View 비활성화 | 정상 연출을 더 기다리지 않고 논리 공격을 완료한다. 대상이 유효하면 피해가 적용된다. |
| 대상 View만 비활성화 | 논리 대상은 유지하므로 공격 결과에 영향을 주지 않는다. |
| View 파괴 | 다음 Runner 갱신에서 논리 유닛을 제거한다. 단순 비활성화와 다르다. |
| 행동 중 공격자 또는 이동 유닛 제거 | 해당 행동을 즉시 정리한다. 제거된 공격자의 대기 공격은 피해를 적용하지 않는다. |
| 발행된 공격의 대상 제거 | 공격 완료 대기는 유지한다. 연출 종료 후 완료 검증에서 피해 없이 행동을 해제하며 AP는 환불하지 않는다. |
| Runner 비활성화 | 미발행 경로·공격 예약은 취소한다. 발행된 이동은 연출 없이 완료하고, 발행된 공격은 논리 완료와 유효한 대상의 피해 처리를 한 번 수행한다. |
| Runner 파괴·전투 연결 해제 | 위 행동 정리 후 View 연결과 내부 참조를 해제한다. Runner가 생성한 View는 파괴하고 외부에서 배치한 View는 연결을 해제하여 보존한다. |

개별 사망 또는 명시적 `RemoveCharacter()`에서는 논리 유닛·점유를 제거하고 View를 비활성화한다. Runner가 생성한 View이면 파괴까지 수행하고, 씬에 배치된 View이면 비활성 상태로 남긴다. 현재 턴 유닛이 외부 제거되고 양 진영이 남아 있으면 다음 생존 유닛의 턴을 시작한다.

초기 바인딩에는 모델, Animator, Idle/Walk 상태와 유효한 이동 속도가 필요하다. 기본 상태 이름은 `Base Layer.Idle`, `Base Layer.Walk`, `Base Layer.Attack`이며 설정에서 바꿀 수 있다. 정상 Attack 연출은 유효한 Motion, 양의 재생 속도, 비반복 상태, 자동 전환 없음이 전제다. 연출 설정 오류는 기존 오류 로그로 알리며 이미 발행된 논리 공격의 취소 사유로 삼지 않는다.

### 3.8. 적 AI

- 현재 적의 턴이며 진행 중인 행동이 없을 때 다음 결정을 내린다. 결정 생성 자체는 자원을 소비하지 않는다.
- 각 아군의 공격 가능한 빈 인접 hex까지 최단 접근 거리를 비교한다. 이미 인접하면 거리 0이며, 도달할 경로가 없는 대상은 제외한다.
- 최소 거리가 같으면 작은 유닛 ID를 선택한다. 같은 대상의 동거리 경로는 고정된 이웃 탐색 순서를 따른다.
- 인접 대상과 AP가 있으면 공격한다. 완료 후 다시 판단하여 가능한 만큼 반복한다.
- 인접 대상이 없으면 AP가 부족해도 남은 이동력으로 접근한다. 한 턴에 도착하지 못하면 경로의 일부까지만 별도 이동 명령으로 이동한다.
- 인접 대상은 있지만 AP가 부족하거나 더 진행할 수 없으면 턴을 종료한다.
- 행동 명령이 거부되거나 일반 이동 연출 실패로 행동을 중단한 경우, Runner는 같은 적의 실패를 반복하지 않고 턴을 종료하도록 처리한다.
- AP를 의도적으로 비축하는 계획, 스킬 사용, 행동 예고는 없다.

### 3.9. 입력과 UI

| 입력 | 동작 |
|---|---|
| 빈 hex 좌클릭 | 현재 턴인 아군에게 이동 명령 |
| 적 Collider 좌클릭 | 부모의 `HexCharacterView`로 대상을 식별하여 공격 명령 |
| UI 밖 우클릭 | 현재 행동의 취소 가능한 예약 제거 |
| 턴 종료 버튼 또는 기본 E키 | 플레이어 턴 수동 종료. 행동 중에는 거부 |

- 조작 대상은 현재 턴의 아군으로 자동 전환된다. 적 턴에는 플레이어 행동 입력을 받지 않는다.
- `GraphicRaycaster`의 UI 적중 결과만 포인터의 UI 차단에 사용한다. 월드 Collider 적중 자체를 UI로 판단하지 않는다.
- HUD에 라운드, 현재 유닛·진영, HP, AP, 남은 이동력과 진행 상태를 표시한다.
- 턴 표시와 체력바는 캐릭터 머리 위 월드 좌표를 화면 좌표와 Canvas 로컬 좌표로 변환하여 표시한다. 월드 공간 Sprite를 배치하는 방식은 아니다.
- 현재 턴 유닛에는 글자 없는 심볼을 표시한다. HP는 초기 HP 수만큼 생성한 가늘고 긴 사각형으로 표시한다. 감소한 HP의 오른쪽 분절을 비활성화하며 남은 분절의 위치는 유지한다.
- 오버레이는 클릭을 가로채지 않는다. 화면 밖·카메라 뒤 또는 비활성 View의 오버레이는 숨기고, 다시 표시 가능한 상태가 되면 복원한다.
- 화면 좌표 변환은 Screen Space Overlay와 Screen Space Camera Canvas를 지원한다. World Space Canvas는 표시 대상에서 제외한다.
- Canvas는 씬에 직접 존재한다. HUD와 유닛 오버레이는 별도 프리팹이며, HUD는 씬의 프리팹 인스턴스, 유닛 오버레이는 등록 유닛에 맞춰 런타임 생성·제거된다.

## 4. 확정된 전투 규칙과 기획

이 절은 확정된 전투 규칙과 기획을 기록한다. 구현 여부는 각 항목의 상태를 따르며, 미구현 항목의 구현 순서와 시점은 별도로 정한다. 실행 검증의 범위와 시점은 7절에서 별도로 확인한다.

새 기능의 범위와 동작을 합의하면 이 절에 추가한다. 각 항목에는 다음 내용을 기록한다.

- 기대 동작과 적용 범위
- 시작·완료 조건 및 비용 적용 시점
- 실패·취소·대상 제거 시의 처리
- 관련 기존 규칙과 담당 컴포넌트
- 구현 완료를 판단할 테스트 또는 확인 조건

### 4.1. 공격 속성과 속성별 방어력

- 상태: **기획 확정·미구현**
- 확정일: 2026-10-17
- 적용 범위: 모든 공격의 속성과 해당 속성에 대한 방어력의 피해 경감 규칙

속성은 **물리, 물, 불, 전기, 독, 무속성**의 6가지다. 모든 공격에는 속성이 있으며, 별도로 명시하지 않은 공격의 속성은 **물리**다. 무속성은 별도로 지정하는 속성이다.

방어력은 **물리 방어력, 물 방어력, 불 방어력, 전기 방어력, 독 방어력**의 5가지로 각각 존재한다. 각 방어력은 같은 속성의 공격으로 받는 대미지만 고정 수치만큼 줄인다. 다른 속성의 방어력은 해당 공격의 대미지 계산에 적용하지 않는다. 무속성 방어력은 존재하지 않는다.

아래 계산에서 공격 대미지는 4.2절의 치명타 추가 대미지까지 반영한 방어력 적용 전의 값이다.

| 공격 속성 | 방어력 적용 후 대미지 |
|---|---|
| 물리 | `max(0, 공격 대미지 - 물리 방어력)` |
| 물 | `max(0, 공격 대미지 - 물 방어력)` |
| 불 | `max(0, 공격 대미지 - 불 방어력)` |
| 전기 | `max(0, 공격 대미지 - 전기 방어력)` |
| 독 | `max(0, 공격 대미지 - 독 방어력)` |
| 무속성 | 방어력의 영향을 받지 않는 고정 대미지. 공격 대미지를 그대로 적용한다. |

**최소 대미지는 0**이다. 방어력이 공격 대미지 이상이면 대미지는 0이 되며, HP를 감소시키거나 회복시키지 않는다. 예를 들어 물리 대미지 5를 물리 방어력 2인 유닛이 받으면 대미지는 3이다. 물리 방어력이 5 또는 6이면 대미지는 0이다.

기본 공격의 AP 소비 시점, 피해 적용 시점, 취소와 대상 제거 처리는 3.5~3.7절의 기존 규칙을 따른다. 실제 HP 감소량은 피해 무효화 등 확정된 효과까지 반영한 최종 대미지와 대상의 남은 HP 중 작은 값이다. 수호자의 방향별 물리 대미지 무효화와 기존 전사 프로토타입과의 구분은 4.4절·4.8.1절을 따른다. 장비의 방어력 파괴·무시와 피해 차단·반격은 4.10절의 확정 범위와 미정 경계를 구분한다.

치명타와의 관계는 4.2절을 따른다. 정령궁수의 Lv2 기본 공격은 4.13절에 따라 하나의 공격 안에 물·불·전기·독 피해 성분을 가지며 각 성분에 해당 방어력을 개별 적용한다. 전사·도적·궁수의 초기 테스트용 방어력은 4.4절을 따른다. 초기 테스트 범위 밖의 방어력 수치와 부여 방식, 그 밖의 피해 증감 규칙과의 관계는 아직 확정하지 않았다. 이 절은 속성과 방어력의 기획을 기록하며, 데이터 구조나 코드 구현이 완료되었다는 의미는 아니다.

구현 후에는 다음 조건을 확인한다. 아래 항목은 향후 확인 기준이며 실행 결과가 아니다.

- 속성을 별도로 명시하지 않은 공격에 물리 속성을 적용한다.
- 물리·물·불·전기·독 공격 각각에 대응하는 방어력만 적용하고, 다른 속성의 방어력은 영향을 주지 않는다.
- 공격 대미지 5와 해당 속성 방어력 2의 계산 결과는 3이다.
- 해당 속성 방어력이 공격 대미지와 같거나 더 높으면 계산 결과는 0이며 HP가 변하지 않는다.
- 치명타가 발생하지 않은 무속성 대미지 5는 다섯 속성의 방어력 수치와 관계없이 5로 유지된다.

### 4.2. 치명타

- 상태: **기획 확정·미구현**
- 확정일: 2026-10-17
- 적용 범위: 무속성을 포함한 모든 속성의 공격

치명타는 매 공격마다 발생 여부를 판정한다. **치명타 확률은 유닛별 능력치**이며, 반드시 치명타가 발생하는 별도 조건이 없으면 공격자 자신의 치명타 확률을 사용한다. 4.4절의 도적 후면 공격처럼 강제 치명타 조건을 만족하면 이 확률과 관계없이 치명타가 발생한다. 전사·도적·궁수의 초기 테스트용 치명타 확률은 4.4절의 기본 능력치 표를 따른다.

치명타가 발생하면 **공격 대미지에 2를 더한다.** 추가 대미지 계산식은 추후 별도로 정할 수 있으나, 현재 확정한 기본 추가 대미지는 공통으로 2다. 기본 규칙에서는 추가분이 원래 공격의 속성을 따르며, 방어력을 차감하기 전에 공격 대미지에 합산한다. 정령궁수의 Lv2 기본 공격은 예외로 **무속성 피해 +2를 공격 전체에 한 번만 추가**하며 네 속성 성분마다 중복하지 않는다. 세부 범위는 4.13절을 따른다. 4.10절의 단검·자비는 치명타 대미지 +1 효과를 가지며, 그 보너스의 계산 위치와 중복 장착 계산은 별도 확정이 필요하다.

아래 표의 기본 대미지는 치명타와 방어력을 적용하기 전의 공격 대미지다. 표와 검증 예시는 단검·자비 등 장비 보정이나 정령궁수의 다속성 기본 공격 예외가 없는 공통 계산이다.

| 공격 속성 | 일반 공격 대미지 | 치명타 대미지 |
|---|---|---|
| 물리·물·불·전기·독 | `max(0, 기본 대미지 - 해당 속성 방어력)` | `max(0, 기본 대미지 + 2 - 해당 속성 방어력)` |
| 무속성 | 기본 대미지 그대로 | `기본 대미지 + 2` |

**무속성 공격에도 치명타가 발생한다.** 무속성의 고정 대미지는 방어력의 영향을 받지 않는다는 뜻이며, 치명타의 추가 대미지는 적용한다. 기본 대미지 5인 무속성 공격은 일반 공격이면 5, 치명타이면 7의 대미지를 준다.

최소 대미지 0과 남은 HP 이하로 실제 HP 감소량을 제한하는 규칙은 동일하게 적용한다. 기본 대미지 5, 해당 속성 방어력 6이면 일반 공격은 0, 치명타는 1이다. 방어력이 7 이상이면 치명타도 대미지가 0이다. 기본 공격의 AP 소비, 피해 적용 시점, 취소와 대상 제거 처리는 3.5~3.7절을 따른다.

구현 후에는 다음 조건을 확인한다. 아래 항목은 향후 확인 기준이며 실행 결과가 아니다.

- 강제 치명타 조건이 없으면 공격자 자신의 치명타 확률을 사용하며, 서로 다른 유닛의 확률을 구분한다.
- 강제 치명타 조건이 없을 때 확률이 0%이면 발생하지 않고, 100%이면 매 공격에 발생한다.
- 도적의 후면 공격은 치명타 확률이 0%여도 치명타가 발생하며, 일반 확률과 중복하여 추가 대미지를 더하지 않는다.
- 기본 대미지 5와 해당 속성 방어력 2에서 일반 공격은 3, 치명타는 5의 대미지를 준다.
- 공통 치명타 계산은 추가 대미지 2를 합산한 뒤 방어력을 차감하며, 최종 대미지가 0 아래로 내려가지 않는다. 정령궁수의 다속성 공격은 4.13절의 무속성 추가 피해 예외를 별도로 확인한다.
- 기본 대미지 5인 무속성 치명타는 다섯 속성의 방어력 수치와 관계없이 7의 대미지를 준다.

### 4.3. 바라보는 방향과 정면·후면

- 상태: **구현 완료**
- 확정일: 2026-10-17
- 판정 기준 갱신일: 2026-10-18. 현재 코드와 기존 테스트의 판정을 기준으로 문서를 정정했다.
- 적용 범위: 유닛의 방향 변경과 전사·도적이 공통으로 사용하는 공격 방향 판정

유닛의 바라보는 방향은 헥스의 6방향 중 하나로 관리한다. 이동 step을 발행할 때 이동 방향을 바라보고, 공격 step을 발행할 때 대상 방향을 바라본다. 피격 시에는 기존 방향을 유지한다. 방향 변경은 이동·공격에 따라 자동으로 적용한다.

정면·후면은 **수비자의 바라보는 방향과 공격자의 타일 위치**를 기준으로 구분한다. 정면 영역의 꼭짓점은 수비자에서 바라보는 방향으로 한 칸 떨어진 인접 타일의 중심이고, 후면 영역의 꼭짓점은 그 반대 방향으로 한 칸 떨어진 인접 타일의 중심이다. 각 꼭짓점에서 수비자 바깥쪽으로 펼쳐지는 120° 부채꼴을 사용하며, 근접·원거리 공격에 같은 기준을 적용한다.

| 구분 | 타일 범위 |
|---|---|
| 정면 | 정면 인접 타일 중심을 꼭짓점으로, 바라보는 방향을 중심축으로 하는 **120° 부채꼴**. 꼭짓점 타일과 그 꼭짓점에서 중심축 기준 좌우 60°로 뻗는 경계 위의 타일을 포함한다. |
| 후면 | 후면 인접 타일 중심을 꼭짓점으로, 바라보는 방향의 반대 방향을 중심축으로 하는 **120° 부채꼴**. 꼭짓점 타일과 그 꼭짓점에서 중심축 기준 좌우 60°로 뻗는 경계 위의 타일을 포함한다. |
| 그 외 방향 | 수비자의 타일을 제외하고 정면·후면 영역에 속하지 않는 타일. 인접한 측면 타일도 포함하며, 정면·후면에 속한 경계 타일은 포함하지 않는다. |

두 부채꼴은 각각의 꼭짓점에서 먼 타일까지 이어진다. 실제 공격 가능 거리는 수비자와 공격자 사이의 헥스 거리 및 사용하는 공격의 사거리로 별도 제한한다. 정면·후면·그 외 방향은 서로 겹치지 않는다.

예를 들어 동쪽을 바라보면 동쪽 인접 타일은 정면, 서쪽 인접 타일은 후면이며 북동쪽·남동쪽·북서쪽·남서쪽 인접 타일은 측면이다. **인접한 6개 타일은 정면 1개·후면 1개·측면 4개로 나뉜다.** 수비자 좌표를 `(0, 0)`으로 놓으면 후면 꼭짓점은 `(-1, 0)`이고, `(-2, 1)`과 `(-1, -1)`은 후면 경계에 포함된다. 인접 타일 `(-1, 1)`과 `(0, -1)`은 측면이다.

현재 프로토타입의 전사 방향별 물리 대미지 무효화와 도적의 후면 치명타는 `BattleFacing.Classify`의 공통 분류를 사용한다. 초기 방향은 유닛 등록 시 지정한다. 공격할 때는 대상과 가장 가까운 헥스 방향을 선택하며, 대상이 두 방향의 정확한 중간에 있으면 시계 방향 쪽을 선택한다.

수호자 Lv5의 방향 판정 확장은 4.8.1절의 기획 확정·미구현 예외다. 아래 공통 분류와 현재 구현 검증을 수호자의 새 규칙으로 그대로 적용하지 않는다. 인접한 6칸의 예외는 확정했지만 먼 타일의 확장 영역·경계는 미정이다. 경계사격은 4.9절의 사용자 현재 Hex 중심을 꼭짓점으로 하는 별도 120° 영역을 사용한다.

다음 조건을 공통 기본 분류의 확인 기준으로 유지한다. 아래 항목은 확인 기준이며 이번 문서 정정에서 테스트를 실행한 결과가 아니다.

- 6가지 바라보는 방향 모두에서 정면·후면 인접 타일 중심을 각각 꼭짓점으로 하는 120° 영역을 사용하며, 꼭짓점과 경계 타일이 해당 영역에 포함된다.
- 수비자가 점유한 타일을 제외한 각 타일은 정면·후면·그 외 방향 중 하나로만 분류된다.
- 인접한 6개 타일은 정면 1개·후면 1개·측면 4개로 나뉘고, 먼 타일에도 각 인접 타일 중심을 꼭짓점으로 하는 같은 영역 판정을 적용한다.
- 이동·공격에 따라 공격자 자신의 방향이 바뀌며, 피격만으로 수비자의 방향이 바뀌지 않는다.

### 4.4. 직업 — 전사·도적·궁수와 기사

- 확정일: 2026-10-17

**초기 테스트용 기본 능력치**

아래 수치는 직업별 능력·이동력·사거리의 차이를 확인하기 위한 초기 테스트값으로 확정한다. 최종 밸런스가 아니며, 현재 코드나 씬에 적용된 값은 아니다. 현재 구현의 설정값은 3.2절과 구분한다.

| 직업 | HP | 기본 공격 대미지 | 이동력 | 기본 공격 사거리 | 치명타 확률 |
|---|---:|---:|---:|---:|---:|
| 전사 | 10 | 3 | 2 | 1 | 5% |
| 도적 | 8 | 3 | 4 | 1 | 15% |
| 궁수 | 8 | 3 | 2 | 3 | 10% |

HP는 전투 시작 시의 HP, 이동력은 자신의 턴마다 갱신되는 이동력, 사거리는 헥스 거리 기준 기본 공격의 최대 사거리를 뜻한다. 기본 공격 대미지는 치명타와 방어력을 적용하기 전의 값이다.

초기 테스트의 공통 조건은 다음과 같다.

- 전문화 보정 전 세 직업의 기본 공격 속성은 물리다. 정령궁수의 Lv2 기본 공격 교체는 4.13절을 따른다.
- 전사의 물리 방어력은 1이며, 전사의 물·불·전기·독 방어력과 도적·궁수의 다섯 속성 방어력은 모두 0이다. 무속성 방어력은 두지 않는다.
- 시작 AP 4, 최대 AP 8, 자신의 턴당 AP 부여량 4, 기본 공격 AP 비용 2를 유지한다. 첫 턴의 AP 처리와 이월 규칙은 3.3절을 따른다.
- 치명타의 추가 대미지는 4.2절에 따라 2이며, 도적의 후면 공격은 표의 일반 치명타 확률과 관계없이 반드시 치명타가 발생한다.

**전사 — 새 기획**

- 근접 무기를 능숙하게 다루고 공격 기회를 활용하는 직업이다. 전사 전체를 탱커로 전제하지 않으며 방어·보호 전문성은 수호자에 집중한다.
- 물리 방어력 1 등 기존 기본 능력치는 이번 변경으로 바꾸지 않는다.
- 새 기본 패시브는 **기회 공격**이다. 인접한 적이 일반 이동으로 인접 상태를 벗어나려는 1칸 이동을 선언하면 실제 이동 전에 해당 적에게 기본 공격 한 번을 가한다.
- AP를 소비하지 않는다. 보유자 한 명은 같은 대상에게 같은 라운드 동안 최대 1회 발동하고, 서로 다른 대상에는 각각 발동할 수 있다. 라운드 전체 총횟수 제한은 없으며 대상별 기록은 새 라운드 시작에 초기화한다.
- 강제 이동과 기술 이동에는 발동하지 않는다. 이동 취소·잔여 경로 폐기·복수 반응의 예약과 우선권·미실행 반응 보존은 4.11절을 따른다. 이동 봉쇄·속박·아군 대신 피격을 공통 능력에 추가하지 않는다.

**수호자 Lv2의 방향별 물리 피해 차단 — 기획 확정·미구현**

- 방향별 물리 피해 차단은 수호자 Lv2 고정 패시브로 습득한다. 일반 방패는 물리방어 +1을 제공하며 차단을 자동 부여하지 않는다.
- 물리 피해를 방향별 확률로 무효화하는 효과는 유지한다. 무효화되면 치명타 여부와 관계없이 물리 피해는 0이며, 무효화되지 않으면 해당 유닛의 물리 방어력을 적용한다. 물·불·전기·독·무속성 공격을 차단하지 않는다.
- 기존 전사 프로토타입의 정면 50%·측면 10%·후면 0%를 수호자 패시브의 테스트 기준으로 사용한다. 이후 밸런싱에서 조정할 수 있다.
- 수호자 Lv5의 정면 확장은 4.8.1절을 따른다. Lv2 차단 습득과 Lv5 방향 확장을 서로 다른 레벨 보상으로 적용한다.
- ClassDefinition의 기존 전사 능력 목록과 AbilitySettings의 차단 설정을 수호자 보상으로 연결하는 데이터 계약은 MercenarySystem의 후속 설계를 따른다. 기존 코드·에셋·관측된 프로토타입 동작을 이미 교체했다고 해석하지 않는다.

**도적**

- 다른 두 직업보다 높은 기본 이동력을 가진다. 초기 테스트 수치는 위 기본 능력치 표를 따른다.
- 공격자가 수비자의 **후면 120° 부채꼴 영역**에 있으면 반드시 치명타가 발생한다. 후면은 4.3절의 공통 방향 판정을 따른다.
- 공통 기본 방향 판정에서는 기본 공격 사거리 1일 때 바로 뒤 한 칸에서 후면 보너스를 받는다. 사거리가 더 긴 공격은 후면 인접 타일 중심에서 펼쳐지는 영역 안과 경계 타일에서도 받는다. 수호자 Lv5는 앞쪽 양옆을 정면으로 바꾸며 후면을 측면으로 바꾸지 않으므로 기존 후면 조건은 유지된다.
- 후면 보너스는 인접 여부와 관계없이 적용한다. 사용하는 공격의 사거리 안에 있다면 원거리 공격에서도 받을 수 있다.
- 후면 조건을 만족하지 않으면 자신의 일반 치명타 확률을 사용한다. 후면 치명타에도 4.2절의 추가 대미지 2를 한 번 적용하며, 무속성 공격에도 같은 규칙을 적용한다.

**궁수**

- 원거리에서 공격할 수 있다.
- 초기 테스트의 기본 공격 사거리는 3이다. 긴 사거리는 직업 기본 수치·공격 특성이며 별도 Lv1 패시브로 취급하지 않는다.
- Lv1 기본 패시브는 전투 종료 시 특수화살 1개를 제작하는 전투 외 준비 능력이다. 특수화살과 제작 대상 전투 종료의 구체 계약은 4.13절을 따른다. Lv1 액티브 경계사격은 4.9절을 유지한다.

기사는 데스메리온에게 맹세하여 특별한 힘을 얻고 양손 무기를 사용하는 신규 기본 직업이다. 강제 이동 면역·강타·기어스는 4.12절을 따른다. 위 세 직업의 테스트 표를 기사에게 그대로 복사하지 않으며 기사의 기본 능력치·공격 설정은 미정이다. 모든 유닛이 가지는 우선권과 라운드 순서는 4.11절을 따른다.

초기 테스트 이후의 최종 밸런스와 위에 명시하지 않은 직업별 능력치·공격 설정은 아직 확정하지 않았다. 원거리 공격의 사선·장애물 규칙도 별도 결정 사항이다.

구현 후에는 다음 조건을 확인한다. 아래 항목은 향후 확인 기준이며 실행 결과가 아니다.

- 각 직업에 위 표의 HP·기본 공격 대미지·이동력·사거리·치명타 확률과 초기 테스트용 방어력이 적용된다.
- 전사의 기본 물리 방어력 1, 방패의 물리방어 +1과 수호자 Lv2 차단을 구분한다. 방패 장착만으로 방향 차단이 생기지 않는다.
- 수호자 Lv2 차단에 정면 50%·측면 10%·후면 0% 테스트 기준을 적용하고, 물리 피해 무효화를 다른 속성의 공격에 적용하지 않는다.
- 전사의 기회 공격은 일반 이동의 인접 이탈 선언에만 발동하며 AP 0, 보유자·대상별 라운드 1회와 4.11절의 취소·예약 규칙을 따른다.
- 공통 기본 분류에서는 기본 공격 사거리 1인 도적이 바로 뒤 한 칸에서 후면 강제 치명타를 받는다. 수호자 Lv5가 앞쪽 양옆을 정면으로 확장해도 후면 조건은 유지된다.
- 도적이 수비자의 뒤쪽 중심선에서 벗어나더라도 후면 부채꼴 안이나 경계 타일에 있으면 반드시 치명타가 발생한다.
- 도적의 후면 보너스가 사거리 안의 원거리 공격에도 적용되고, 정면·측면에서는 강제 치명타가 발생하지 않는다.
- 궁수가 기본 공격 사거리 3헥스 안에서 원거리 공격을 수행한다.

목표는 적도 기존 직업 능력을 활용하여 플레이어가 후면 보호와 원거리 적에게 접근하는 방법을 판단하게 하는 것이다. 이번 단계는 현재 턴의 이동·기본 공격 선택만 다룬다. 전사는 기존 최단 접근·기본 공격 방식을 유지한다.

**공통 판단과 실행**

- 현재 적의 턴이며 진행 중인 행동이 없을 때 판단한다. 이동·공격이 완료되면 남은 자원과 최신 전장 상태로 다시 판단한다.
- 공격 후보는 살아 있는 상대 진영 유닛과 그 유닛을 기본 공격할 수 있는 위치의 조합이다. 현재 위치도 후보에 포함하며, 다른 위치는 유효한 빈 타일이고 다른 유닛을 통과하지 않는 경로가 있어야 한다.
- 4.6절의 은신 규칙에 따라 AI는 은신한 적을 보이지 않는 것으로 취급한다. 아래의 공격·최단 접근 대상 선택에도 이 인식 제한을 적용한다. 마지막 목격 위치 수색과 범위 공격 처리는 미정이다.
- 이번 턴의 공격 후보는 남은 이동력으로 해당 위치에 도달할 수 있고, 남은 AP로 기본 공격을 한 번 이상 실행할 수 있어야 한다. 각 유닛의 실제 기본 공격 사거리를 사용하며, 도적·궁수의 초기 테스트 사거리는 4.4절을 따른다.
- 아래 직업별 우선순위가 같으면 작은 대상 유닛 ID를 선택한다. 같은 대상의 동등한 위치·경로는 기존의 고정된 6방향 탐색 순서로 결정한다. 후보 평가 자체는 자원이나 치명타·무효화 판정용 난수를 소비하지 않는다.
- 선택한 위치가 현재 위치이면 바로 공격하고, 다른 위치이면 해당 위치까지 이동한 뒤 선택한 대상을 공격한다. 후면이나 사거리를 고려하여 선택한 위치를 일반 최단 접근 위치로 바꾸지 않는다.
- AI는 행동을 선택하고, 이동·공격 가능 여부의 최종 검사와 실행은 공통 전투 규칙이 담당한다. 이동력·AP 소비, 피해 적용 시점, 취소·대상 제거·View 수명 처리는 3.4~3.7절을 따른다. 명령 거부나 일반 이동 연출 실패 시 같은 실패를 반복하지 않고 턴을 종료하는 3.8절의 정책도 유지한다.

**도적 — 이번 턴에 공격 가능한 후면 우선**

1. 이번 턴의 공격 후보 중 대상의 실제 후면으로 판정되는 위치를 우선한다. 후보 위치와 판단 시점의 수비자 방향에 4.3절의 공통 분류 및 4.8.1절의 확정된 수비자 방향 보정을 함께 적용한다. 보정이 없는 공통 분류는 후면 인접 타일 중심에서 펼쳐지는 120° 영역과 경계를 사용하며, 기본 공격 사거리 1에서는 바로 뒤 한 칸이 후면 후보가 된다. 수호자 Lv5는 후면을 측면으로 바꾸지 않으므로 기존 후면 후보를 제거하지 않는다. 미정인 원거리 확장 영역은 별도 계약을 정한 뒤 적용한다.
2. 후면 후보끼리는 실제 이동 경로가 짧은 것을 선택한다. 현재 위치가 후면이면 이동 거리 0으로 취급한다.
3. 후면 후보가 없으면 후면이 아닌 공격 후보 중 실제 이동 경로가 가장 짧은 것을 선택한다. 현재 가능한 일반 공격을 포기하고 이번 턴에 공격할 수 없는 후면까지 우회하지 않는다.

현재 위치에서 후면이 아닌 공격이 가능하더라도, 이동 후 후면 공격까지 가능한 후보가 있으면 후면 이동을 우선한다. 공격 AP가 부족한 경우에는 후면 확보를 위한 우회를 하지 않는다. 후면 치명타의 효과는 4.4절을 따르며 AI 전용 보너스는 없다.

**궁수 — 제자리 공격과 사거리 활용**

1. 현재 위치에서 기본 공격할 수 있고 AP가 충분한 상대가 하나라도 있으면 이동하지 않고 공격한다. 대상이 여럿이면 작은 유닛 ID를 선택한다. 가까이 붙은 적에게도 제자리 공격을 우선한다.
2. 현재 위치에서 공격할 상대가 없으면 이번 턴의 공격 후보 중 공격 대상과의 헥스 거리가 가장 큰 위치를 선택한다. 위치는 반드시 자신의 기본 공격 사거리 안에 있어야 한다.
3. 대상과의 거리가 같은 후보끼리는 실제 이동 경로가 짧은 것을 선택한다. 남은 동률은 공통 기준을 따른다.

여기서 유지하는 거리는 선택한 공격 대상과의 거리다. 다른 적 전체의 위협이나 다음 턴의 안전한 위치를 평가하지 않는다. 공격을 위해 이동할 때 사거리를 활용하며, 공격 전의 별도 회피 이동이나 공격 후 후퇴는 이번 범위에 포함하지 않는다.

**이번 턴에 공격할 수 없을 때**

- AP 부족 또는 이동력 부족으로 이번 턴의 공격 후보가 없으면 기존 최단 접근 방식을 사용한다. 접근 목적지는 각 유닛의 기본 공격 사거리 안에 있는 유효한 빈 타일이며, 사거리를 일괄적으로 1로 취급하지 않는다.
- 대상별 최단 접근 거리를 비교하고, 동률이면 작은 대상 유닛 ID를 선택한다. 한 턴에 도착할 수 없으면 남은 이동력만큼 경로의 일부를 이동한다. AP가 부족해도 이 접근은 가능하다.
- 이미 현재 위치에서 사거리가 닿는 상대가 있고 AP만 부족하면 추가 접근 없이 턴을 종료한다. 공격 가능한 상대가 없고 이동력도 없거나, 접근 경로가 없거나, 접근을 더 진행할 수 없으면 턴을 종료한다.

여러 턴 예측, 턴 전체의 공격 횟수 최적화, 처치·예상 피해량에 따른 대상 우선순위, 아군 연계, 스킬·특전 활용, 의도적인 AP 비축과 행동 예고는 이번 확정 범위에 포함하지 않는다. 이후 전투 기능을 추가할 때 필요한 AI 판단을 별도로 정한다.

구현 후에는 다음 조건을 확인한다. 아래 항목은 향후 확인 기준이며 실행 결과가 아니다.

- 도적은 현재 위치에서 일반 공격이 가능해도 남은 이동력과 AP로 실제 후면 이동·공격이 가능하면 후면 후보를 선택한다. 보정 없는 공통 분류에서 사거리 1은 바로 뒤 한 칸, 더 긴 사거리는 해당 후면 영역·경계를 사용한다. 수호자 Lv5 적용 후에도 유지되는 후면 후보를 잘못 제외하지 않는다. 미정인 원거리 보정은 계약 확정 후 검증한다.
- 후면까지의 경로가 막혀 있거나 이번 턴에 도달할 수 없으면 도적은 가능한 일반 공격을 수행한다. AP가 부족하면 후면 확보를 위한 우회를 하지 않는다.
- 궁수는 현재 위치에서 공격할 상대가 있으면 다른 상대를 향해 불필요하게 이동하지 않고 제자리에서 공격한다.
- 궁수가 이동 후 공격할 때는 도달 가능한 공격 후보 중 대상과의 거리가 가장 큰 위치를 선택하며, 사거리 밖으로 벗어나 공격을 놓치지 않는다.
- 직업별 우선순위가 같은 후보는 이동 거리·대상 ID·고정 탐색 순서에 따라 일관되게 선택한다.
- 이번 턴에 공격할 수 없을 때는 각자의 사거리를 반영하여 부분 접근하거나 턴을 종료한다. AP·이동력 부족, 막힌 경로와 행동 실패로 무한 재판단하지 않는다.
- 행동 완료 후에는 최신 상태로 다시 판단하며, 이동·공격 비용과 대상 제거·취소 처리는 공통 규칙과 동일하다.

### 4.6. 공통 은신과 투명화

- 상태: **기획 확정·미구현**
- 확정일: 2026-10-28
- 적용 범위: 모든 직업의 공통 은신 행동, 시야 발각·AI 인식·턴 시작 이동력과 투명화의 관계

은신은 주변 배경에 몸을 숨기는 공통 기술로 누구나 사용할 수 있다. 도둑의 전용 습득 스킬로 두지 않는다. 일반 은신은 감지하는 적의 정면과 정면 양옆으로 펼쳐지는 시야 구역에 들어가면 발각된다. AI는 은신한 적을 보이지 않는 것으로 취급한다.

정확한 헥스 모양·감지 거리·장애물에 의한 시야 차단은 미정이다. 4.3절의 공격 정면·후면 판정 범위를 그대로 발각 범위로 확정하지 않는다. 도둑의 패시브는 4.7.2절에 따라 해당 도둑을 발견하는 범위만 보정한다.

**사용과 자원**

- 공통 은신의 사용 비용은 **2 AP와 현재 이동력 2**다. 사용 시점에 어떤 적의 시야에도 닿지 않을 때만 사용할 수 있다.
- 사용 뒤 AP나 이동력이 남으면 턴을 끝내지 않고 계속 행동할 수 있다.
- 은신 중에는 턴 시작에 지급하는 이동력을 **1 줄인다.** 이 값은 현재 테스트용이며 밸런싱에서 조정할 수 있다. 이동 애니메이션 속도나 한 칸 이동 비용은 바꾸지 않는다.
- 턴 도중 은신을 시작해도 상태 페널티 때문에 현재 남은 이동력을 추가로 차감하지 않는다. 은신 사용 비용인 이동력 2는 정상 지불한다. 턴 도중 해제에 따른 이동력 지급량 재정산은 별도 설계한다.

**발각과 해제**

- 은신 캐릭터가 일반 이동 또는 강제 이동으로 1칸 이동한 뒤, 적이 일반 이동 또는 강제 이동으로 1칸 이동한 뒤, 적의 Facing이 변경된 뒤마다 발각을 검사한다.
- 검사 결과 하나 이상의 적 시야에 닿으면 즉시 은신을 해제한다. 도둑에게 적용하는 시야 발각 보정은 4.7.2절을 따른다.
- 은신 상태에서 피해를 받으면 즉시 은신을 해제한다.
- 은신 진입 행동을 제외한 AP 소비 행동은 **그 행동의 조건 판정과 효과 처리를 모두 마친 뒤** 은신을 해제한다. 해당 행동은 완료까지 은신 조건과 은신에서 얻는 효과를 사용할 수 있다. 행동 처리 중 피격이나 적 Facing 변경에 따른 발각이 함께 발생할 때의 상세 우선순위는 별도 설계한다.
- AP를 쓰지 않는 일반 이동은 AP 소비에 의한 해제 대상이 아니며 이동 후 시야 발각 검사는 수행한다.

**투명화**

투명화는 은신 상태로 취급하여 은신을 요구하는 기술의 사용 조건을 충족한다. 적의 시야를 무시하고 은신의 턴 시작 이동력 -1 페널티를 적용하지 않는 점을 제외한 상태 규칙은 일반 은신과 동일하다. 따라서 AP 소비 행동을 모두 처리한 뒤 투명화를 해제하고 피해를 받으면 즉시 해제한다. 암살자 Lv5 구안의 투명화 유지 예외는 철회했으며 대체 기술에 승계하지 않는다.

투명화 부여 스킬은 자신의 AP 비용 때문에 새로 부여한 투명화가 즉시 해제되지 않도록 처리한다. 투명화 획득 수단별 비용·조건·지속 시간은 해당 능력에서 별도로 정하며, 처치 후 새 투명화 부여와 기존 은신의 행동 후 해제가 겹칠 때의 순서·실패·취소 처리는 미정이다.

정확한 시야 거리·차폐/장애물 처리, 기술 이동의 발각 검사와 강제 이동의 중간 칸 표현, 피해 0의 해제 판정, 대상 지정·탐지 기술과의 관계, AI의 마지막 목격 위치 수색·범위 공격 처리는 후속 설계한다. 새 시야 형상이나 지형 사선·엄폐 시스템을 이번 변경으로 확정하지 않는다.

구현 후에는 비용 2 AP·이동력 2, 시야 밖 사용, 잔여 행동, 턴 시작 이동력 -1과 턴 도중 진입 시 추가 차감 없음, 지정한 발각 검사 시점, 피격 즉시 해제 및 AP 행동 완료 후 해제를 확인한다. 투명화에는 시야·이동력 페널티 예외와 나머지 공통 해제를 적용한다. 이는 향후 확인 기준이며 실행 결과가 아니다.

### 4.7. 도적 전문화의 전투 효과

| Lv5 | 고정 액티브 — 교체 예정 | 기존 방어력 무시 물리 공격과 투명화 유지 효과를 철회했다. 더 화려한 기술로 재설계하며 새 효과는 미정이다. |

Lv5 액티브의 사용 조건·비용·피해·대상·이동·투명화 해제 여부는 모두 다시 설계한다. 그림자 연쇄·처형의 순간·일섬과 연속 기습·처치 후 재사용·경로 공격·순간이동·분신은 채택하지 않았다. 구안을 Lv1 암습으로 그대로 이전한 것도 아니다. Lv2 보상과 Lv5 처치 후 투명화 패시브는 유지한다.

정식 스킬명, AP 비용·피해·사거리·사용 횟수 제한과 도약 경로·착지 가능 조건은 미정이다. 투명화의 해제와 처리 순서는 4.6절의 확정 범위와 미정 사항을 따른다. 후방 도약 공격을 투명화 전용 스킬로 제한하지 않는다.

Lv2는 패시브 1개·고정 액티브 1개·선택 액티브 1개를 함께 받는다. 주의 돌리기와 비열한 행동을 서로 대체하지 않는다. 은신 이동력 감소 완화나 Lv5 방해 스킬 사용 후 이동력 회복을 보상에 추가하지 않는다.

주의 돌리기는 방향 변경이며 강제 공격 대상 지정이나 도발 효과가 아니다. 적의 Facing을 변경한 뒤 발각을 검사하며 AP를 사용하는 경우 행동 처리 후 은신 해제는 4.6절을 따른다. 비열한 행동은 Lv2에서 세 후보 중 하나를 선택하는 구조를 유지한다. 실명·약화·넘어짐의 정확한 효과·지속 시간·중첩·AP 비용·사거리·피해 여부·사용 제한은 별도 설계한다. 급소공격과 불한당의 약화가 같은 상태이상을 사용하면 중첩·갱신을 공통 규칙에 맞춘다.

무기 빼앗기의 실제 아이템 획득 여부, 무기를 잃은 적의 기본 공격·스킬 변화와 무기가 없는 인간형 적에 대한 사용 가능 여부는 미정이다. AP를 사용하는 경우 일반 은신·투명화 모두 행동 처리 후 해제를 적용하며 별도 예외로 면제하지 않는다. 각 스킬의 AP 비용·사거리·피해·사용 횟수 제한·실패 및 취소 처리와 무기 빼앗기·패시브의 정식 명칭도 미정이다.

#### 4.7.3. 불한당 — 상태이상 대상 추가 피해와 AP 회복

대화의 ‘불량배’는 기존 불한당과 같은 전문화다. 별도의 네 번째 도적 전문화로 추가하거나 정식 이름을 일괄 변경하지 않는다. 해로운 상태이상이 있는 적을 근접 공격으로 압박하며 동료가 부여한 상태이상도 활용한다.

| 레벨 | 보상 | 확정 효과 |
| --- | --- | --- |
| Lv2 | 고정 패시브 — 약한 놈부터(가칭) | 해로운 상태이상이 하나 이상 걸린 적에게 직접 공격으로 추가 피해를 준다. |
| Lv2 | 고정 액티브 — 비열한 일격(가칭) | 적 하나에게 물리 피해를 준 뒤 약화를 부여한다. 약화된 적은 공격 피해가 감소한다. |
| Lv5 | 고정 패시브 — 기세 몰기(가칭) | 해로운 상태이상이 걸린 적을 공격하여 피해를 주면 AP를 일부 회복한다. 자신의 턴마다 한 번 발동한다. |
| Lv5 | 고정 액티브 — 난타(가칭) | 적 하나를 연속으로 두 번 물리 공격한다. 각 타격에 상태이상 대상 추가 피해와 물리 방어력을 적용한다. |

추가 피해는 대상에게 해로운 상태이상이 하나 이상 있으면 발동하며, 그 개수만큼 증가하지 않는다. 직접 공격 피해에 적용하고 독 등의 지속 피해에 자동 적용하지 않는다. 추가 피해의 조건이 되는 해로운 상태이상의 목록·분류는 미정이다. 독의 지속 피해 자체에 추가 피해를 주지 않는 것과 독에 걸린 대상이 직접 공격의 조건을 충족하는지는 구분한다.

각 타격 시 대상의 상태이상 보유 여부를 확인한다. 비열한 일격처럼 피해 뒤 상태이상을 부여한다면 그 상태이상을 근거로 앞선 피해에 추가 피해를 적용하지 않는다. 다른 해로운 상태이상이 이미 있으면 그 조건으로 적용할 수 있다.

기세 몰기는 공격이 피해를 주어야 발동한다. 모든 공격이 자신의 턴당 한 번 제한을 공유하므로 난타의 두 타격으로 AP를 두 번 회복하지 않는다. 기존 최대 AP를 넘지 않으며, AP 회복과 발동 횟수 소모의 정확한 시점은 별도 설계한다.

능력명은 모두 가칭이다. 추가 피해량·AP 회복량·스킬 AP 비용·사거리·기본 피해·사용 제한과 약화의 감소량·지속 시간·중첩 규칙은 미정이다. 추가 피해의 속성·치명타·방어력과의 정확한 계산 순서, 약화의 공격 피해 감소 범위·계산 순서, 난타 각 타격의 치명타·피해 무효화 판정은 4.1~4.4절과 대조하여 구체화한다. 첫 타격으로 대상이 제거됐을 때의 후속 타격, 실패·취소와 비용 처리는 미정이며, 다른 적 자동 지정이나 비용 환불을 가정하지 않는다.

#### 4.7.4. 향후 확인 기준

아래는 구현 후 확인할 기준이며 이번 문서 작업의 실행 결과가 아니다.

- 일반 은신의 시야 발각과 투명화의 시야 진입 예외가 구분되고 AI 인식에도 반영된다.
- 은신의 이동력 -1이 턴 시작 지급량에 적용되고 턴 도중 진입 시 상태 페널티를 추가 차감하지 않는다. 투명화에는 이 페널티를 적용하지 않는다.
- 암살자의 후방 도약 공격은 투명화 없이도 사용 가능하고 투명화 부여가 자기 AP 비용으로 즉시 해제되지 않는다. 철회된 Lv5 방어력 무시 공격과 투명화 유지 예외를 유효한 보상으로 구현하지 않는다.
- 도둑의 Lv2·Lv5 발각 제한은 해당 도둑에게만 적용되며 투명화의 시야 진입 예외를 없애지 않는다. Lv2의 고정 보상과 선택 보상을 함께 지급한다.
- 비열한 행동은 모래뿌리기·급소공격·발걸기 중 하나를 지급하며 각각 실명·약화·넘어짐을 부여한다. 상태이상 세부 계약을 확정한 뒤 효과·중첩을 검증한다.
- 불한당의 추가 피해는 각 타격 직전의 상태를 기준으로 하며 상태이상 수나 지속 피해에 따라 자동 증식하지 않는다. 난타 두 타격에는 각각 물리 방어력을 적용하고, AP 회복은 실제 피해 발생과 턴당 한 번 제한·최대 AP를 지킨다.

각 액티브의 AP 비용·사용 제한·장비 또는 특성 의존 여부·실패·취소와 비용 처리·정식 명칭은 미정이다. 수호자의 모든 능력을 방패 전용으로 제한하지 않으며 경계·방패 돌진·넓은 방어는 가칭이다.

Lv5 패시브는 자신의 이동에 대한 기회 공격 방지다. 4.11절에 따라 기술 이동·강제 이동은 모든 유닛에게 기회 공격·경계사격을 유발하지 않으며, 이 패시브는 개척자의 일반 이동에 남는 기회 공격을 방지한다. 경계사격까지 막는 효과로 확장하지 않는다. Lv5 이전 끌려가기와 끌어오기·내던지기도 기술·강제 이동이므로 이동 반응을 유발하지 않는다.

#### 4.8.3. 향후 확인 기준

- 수호자 Lv2는 방향별 물리 피해 차단을 얻고 Lv5에서 인접 정면 3칸·후면 1칸·측면 2칸으로 판정한다. 방패 장착 여부와 구분하며 실제 후면의 도적 강제 치명타는 유지한다.
- Lv5의 방향 확장만으로 정면 인접 적의 은신을 항상 해제하지 않는다. 탐지 액티브의 투명화 적용과 먼 타일 영역은 결정 후 검증한다.
- 지원 AP는 각 아군의 다음 자기 턴 시작에 지급하며 수치·상한·시전자 포함 여부를 임의로 가정하지 않는다.
- 개척자 이동력 회복은 자기 기술의 실제 위치 변경과 자기 턴 1회 조건을 모두 검사한다. 일반 이동·실패·AP 회복으로 대체하지 않는다.
- 기술 이동·강제 이동은 기회 공격·경계사격을 유발하지 않는다. 개척자 Lv5의 일반 이동은 기회 공격을 유발하지 않지만 경계사격 조건은 검사한다.

### 4.9. Lv1 직업 액티브 — 암습과 경계사격

- 상태: **기획 확정·미구현**
- 확정일: 2026-10-29
- 두 기술은 전문화 선택 이전의 직업 기술이다. Lv2 전문화·Lv3 공용 특성·Lv4 직업 스킬·Lv5 전문화 강화는 유지한다.

**도적 — 암습**

- 은신 상태이며 대상의 배후에 있을 때만 사용한다. 비용은 **2 AP**이며 자신의 턴마다 최대 한 번 사용한다.
- 기본 공격과 동일한 피해 계산 규칙을 사용하되 해당 공격에 **추가 공격력 +2**를 적용한다. +2는 현재 검증용 수치이며 밸런싱에서 조정할 수 있다. 기본 공격 피해 1.5배 계산은 사용하지 않는다.
- 배후 조건에 따라 도적의 후면 강제 치명타와 치명타 추가 피해를 정상 적용한다. 대상의 물리 방어력도 기본 공격과 동일하게 적용하며 기존 물리 방어력 무시 효과는 제거한다.
- 투명화도 은신 조건을 충족하지만 배후 조건은 별도로 만족해야 한다. 실제 배후 판정에는 4.3절과 4.8.1절의 수비자 방향 규칙을 적용하며, 수호자 Lv5의 정면 확장이 후면을 없애지 않는다.
- 암습의 공격과 효과 처리를 모두 마친 뒤 AP 소비 행동에 의한 은신·투명화 해제를 적용한다. 사용 전에 상태를 해제하여 자신의 은신 조건이나 효과를 잃지 않게 한다.
- 사거리, 실패·취소 시 비용 및 턴당 사용 기록의 처리, 새 투명화 부여 등 다른 후속 효과와의 순서는 별도 설계한다.

**궁수 — 경계사격**

- 준비 비용은 **2 AP**다. 사용자가 6방향 중 감시 방향 하나를 직접 선택하고 실제 Facing을 그 방향으로 변경한 뒤 자신의 턴을 종료하여 경계 상태에 들어간다. 그 영역에 적이 없는 빈 방향도 선택할 수 있다.
- 전방 영역은 사용자 현재 Hex 중심을 꼭짓점으로 하고 선택한 방향을 중심축으로 좌우 60°, 총 **120°**로 뻗는다. 경계를 포함하고 인접 6칸 중 정면 1칸과 좌우 앞쪽 2칸을 포함한다. 4.3절의 공격 정면 판정이나 4.6절의 은신 시야와 구분한다.
- 최대 사거리는 사용자의 기본 공격 사거리와 같다. 120° 전방 영역과 기본 공격 사거리를 모두 만족해야 한다.
- 적이 **1칸 일반 이동을 선언한 직후, 실제 이동하기 전의 현재 위치**로 검사한다. 영역 밖에서 안으로 새로 들어오는 이동에는 그 step에서 발동하지 않으며, 들어온 뒤 다음 일반 이동 선언 때 다시 검사한다.
- 조건을 만족하면 그 이동 step을 취소하고 이동력을 소모하지 않은 채 기본 공격과 동일한 규칙의 공격 1회를 수행한다. 기본 공격 피해·속성·치명타·방어력 계산과 기본 공격에 적용되는 효과를 동일하게 적용하며 발동 자체에는 추가 AP를 소비하지 않는다.
- 실제 공격이 한 번 발동하면 경계 상태를 종료한다. 한 번도 발동하지 않았다면 사용자의 다음 자기 턴 시작에 종료한다. 전투당 한 번 제한을 뜻하지 않는다.
- 경계 중 사용자가 강제 이동되거나 외부 효과로 Facing이 강제로 변경되면 즉시 경계 상태를 종료한다.
- 강제 이동·기술 이동에는 발동하지 않는다. 실제 공격 시 대상 쪽으로 Facing을 변경하며 공격 뒤 그 방향이 남는다. 잔여 경로 폐기, 복수 반응 처리와 미실행 준비 상태 보존은 4.11절을 따른다.
- 은신·투명화한 적에 대한 인식과 공격 사선·차폐, 준비 실패·취소 비용은 별도 설계한다.

전사의 휩쓸기·마법사의 범위 마법·궁수의 견제 사격은 채택하지 않았다. 매 레벨 액티브·패시브 중 선택하는 구조와 Lv3 공용 능력 전반으로의 확장도 미확정이며, Lv4 스킬을 Lv1으로 옮기거나 삭제하지 않는다. 암습은 철회한 암살자 Lv5 기술의 그대로 이전이 아니다.

향후에는 암습의 은신·배후·2 AP·자기 턴 1회, 기본 공격 계산에 추가 공격력 +2와 치명타·방어력을 적용한 뒤 은신 해제하는 순서를 확인한다. 경계사격은 2 AP 준비·빈 방향 선택·Facing 변경·턴 종료, 120° 경계와 기본 사거리, 이동 전 위치 판정, 실제 1회 발동 및 다음 자기 턴·외부 강제 이동/회전 시 종료를 확인한다. 이동 반응의 공통 확인 기준은 4.11절을 따른다. 이는 향후 기준이며 실행 결과가 아니다.

### 4.10. 장비와 전투 효과 — 기획 확정·미구현

#### 4.10.1. 적용 범위

용병마다 부위 구분 없이 최대 3개를 장착하며 같은 종류·동일 장비·동일 특수 장비의 중복을 허용한다. 장비 효과와 수치는 고정하고 무작위 옵션을 사용하지 않는다. 장비가 직업의 기본 공격 방식이나 무기 표현을 바꾸지 않으며 도적에게 대검을 장착해도 단검 전투를 유지한다.

전투 중에는 장비를 변경하지 못한다. 전투 밖의 자유로운 장착·해제·파티원 교환, 무제한 공용 보관, 유한 상점 재고와 판매, 원정 종료 초기화, 일반 장비의 1회 고정 강화와 특수 장비 직접 보상은 [MercenarySystem.md](MercenarySystem.md) 6.10절을 따른다. 특수 장비는 다시 강화하지 않는다. 이 절은 전투 효과의 확정 범위를 기록하며 3절의 현재 구현에 장비 처리가 추가되었다는 뜻이 아니다.

#### 4.10.2. 일반 장비와 고정 강화형

| 일반 장비 | 일반 효과 | 강화형 | 강화형 효과 |
|---|---|---|---|
| 장검 | 물리공격력 +1 | 성검 | 최종 물리공격력 보너스 +2. 적의 물리방어력을 무시한다. |
| 망치 | 공격 피해 계산 후 대상의 물리방어력 1을 누적 파괴한다. | 방패파괴자 | 공격당 물리방어 2를 누적 파괴한다. 적의 물리방어를 0으로 만들면 대상이 1턴 기절한다. |
| 단검 | 치명타 대미지 +1 | 자비 | 기존 치명타 대미지 +1을 유지한다. 공격 피해 적용 후 살아 있는 대상의 현재 HP가 3 이하이면 처형한다. |
| 방패 | 물리방어력 +1. 방향 차단을 부여하지 않는다. | 복수 | 기존 물리방어력 +1을 유지한다. 물리 피해를 받으면 자신의 물리방어력만큼 공격자에게 물리 피해를 준다. |
| 갑옷 | 체력 +2 | 촛농 갑옷 | 기존 체력 +2를 유지한다. 전투 시작 시 다음 피해 1회를 막는 충전을 얻고, 사용 후 착용자의 자기 턴 5턴 뒤 재충전한다. |

성검 1개의 최종 물리공격력 보너스는 +2이며, 방패파괴자 1개의 공격당 최종 물리방어 파괴량은 2로 확정한다. 강화 시 일반 장비의 값 1을 각각 2로 대체한다.

강화는 기존 능력을 삭제하거나 낮추는 교환이 아니며 능력치 증가 자체를 금지하지 않는다. 장검·성검의 공격력 보너스를 기본 공격과 스킬에 적용하는 범위, 단검·자비의 치명타 대미지 +1 계산 위치, 갑옷·촛농 갑옷의 체력 +2와 최대·현재 HP의 연결은 미정이다. 다섯 일반 장비와 강화형 밖의 아이템 목록은 이번 결정에 포함하지 않는다.

#### 4.10.3. 효과 처리와 중복 장착

- **망치·방패파괴자:** 이번 공격은 파괴 전 방어력으로 피해를 계산하고 그 뒤 방어력을 누적 파괴한다. 후속 공격은 감소한 방어력을 사용한다. 해당 공격에만 방어력을 무시하는 효과와 구분한다. 파괴의 유지 기간·하한·중복 장착 계산·적용 공격·범위 및 다단 공격의 발동 단위는 미정이다. 방패파괴자의 양수에서 0으로 바뀔 때만 기절하는지, 초과 파괴·이미 0인 대상 처리와 기절의 행동 제한·해제 시점도 미정이다.
- **자비:** 공격 피해를 적용한 뒤 살아 있는 대상의 현재 HP를 검사한다. 장착 1개는 3 이하, 2개는 4 이하, 3개는 5 이하일 때 처형한다. 장비마다 3을 더하지 않는다. 처형 대상의 예외·처치 효과 연결과 적용 공격 종류는 미정이다.
- **복수:** 각 장비가 개별 발동한다. 자신의 물리방어력이 4이고 복수 3개를 장착했다면 물리 피해 4의 반격 세 번이며 피해 12 한 번으로 합치지 않는다. 우선 이 규칙으로 검증하고 지나치게 강하면 추후 별도 결정으로 변경한다. 반격 연쇄 허용·0 피해 시 발동·참조할 방어력 시점·각 반격의 피해 계산·다른 공격 효과와의 연동은 미정이다.
- **촛농 갑옷:** 전투 시작 시 충전하고 실제로 다음 피해 1회를 막으면 소모한다. 사용 후 재충전의 5턴은 전체 라운드가 아닌 착용자 자신의 턴이며 추가로 부여된 자기 턴도 센다. 이 카운트 규칙이 추가 턴을 주는 기술의 도입을 뜻하지 않는다. 중복 장착 시 같은 피해에 대한 충전 소모·개별 재충전, 턴 시작/종료 중 충전 시점과 발동 중인 현재 턴을 포함할지는 미정이다.

동일 장비의 중복 허용만으로 합산·곱연산·확률·발동 횟수·상한을 일괄 확정하지 않는다. 자비의 처형 기준과 복수의 장비별 개별 발동만 명시한 중첩 규칙으로 적용한다. 수호자의 방향 차단·촛농 갑옷·방어 파괴·기절·처형·반격이 함께 있는 경우의 효과 우선순위, 피해가 0이거나 무효화될 때의 발동 조건과 기본 공격·스킬·반격별 적용 범위는 별도 설계한다.

장착 목록은 전투 중 고정하며 촛농 갑옷의 충전·남은 자기 턴 같은 전투 상태는 공유 장비 정의나 AbilitySettings의 원본 설정과 구분한다. 구체적인 런타임 상태 소유자·필드·저장 및 전투 결과 반영 계약은 미정이다. 방어 파괴의 유지 기간을 정하기 전에는 전투 종료 때 해제된다고 확정하지 않는다.

#### 4.10.4. 구현 후 확인 기준

아래는 향후 검증 기준이며 실행 결과가 아니다. 미정인 계산·발동 경계를 먼저 정한 뒤 검증한다.

- 부위 슬롯 없이 동일 장비 3개를 장착할 수 있고 전투 중 장착·해제·교환을 할 수 없다. 장비 교환으로 직업의 기본 공격 방식이나 무기 표현이 바뀌지 않는다.
- 일반 방패 장착만으로 방향 차단을 얻지 않으며 수호자 Lv2 차단과 Lv5 방향 확장을 구분한다.
- 망치·방패파괴자의 현재 공격은 파괴 전 방어력을 쓰고 이후 공격에는 감소한 방어력이 적용된다. 방어력 무시와 누적 파괴를 구분한다.
- 자비의 공격 후 생존·현재 HP 검사와 장착 1/2/3개에서 기준 3/4/5를 확인한다.
- 물리방어력 4에 복수 3개를 장착한 사례에서 피해 4의 별도 반격 세 번을 생성한다. 피해 12 한 번으로 합치지 않는다.
- 촛농 갑옷은 전투 시작에 충전되고 피해를 한 번 막으면 소모된다. 재충전은 착용자 자신의 5턴으로 세며 다른 유닛의 턴·전체 라운드와 혼동하지 않고 추가 자기 턴도 센다.

### 4.11. 우선권과 일반 이동 반응 — 기획 확정·미구현

#### 4.11.1. 라운드 턴 오더와 반응 순서

모든 유닛은 우선권(`Initiative`) 스탯을 가진다. 라운드 턴 오더는 우선권이 높은 순서로 구성한다. 같은 우선권의 유닛끼리는 라운드 시작에 무작위로 상대 순서를 정하고 해당 라운드 동안 유지한다. 직업별·유닛별 실제 우선권 수치는 미정이다.

이 기획은 3.3절에 기록한 생존 유닛 전체를 무작위로 섞는 현재 구현을 대체할 목표 규칙이다. 기존 코드의 변경 완료를 뜻하지 않는다. 우선권의 실제 데이터 형식·증감 효과·라운드 중 값 변경 처리와 추가 참여자의 정렬은 별도 설계한다.

하나의 이동 선언에 여러 기회 공격·경계사격이 동시에 조건을 만족하면 해당 반응을 모두 예약한다. 반응 유닛의 우선권이 높은 순서로 실행하며, 동률이면 그 라운드에 이미 정한 상대 순서를 사용한다. 반응마다 새로 동률 순서를 뽑지 않는다.

#### 4.11.2. 이동 선언·취소·소비

1. 일반 이동의 경로를 구성하는 **각 1칸 step**을 하나의 이동 선언으로 취급한다. 경로 전체를 하나의 선언으로 검사하지 않는다.
2. 각 step의 실제 좌표·점유 변경과 이동력 차감 전에 현재 위치와 선언한 이동으로 기회 공격·경계사격의 조건을 검사한다. 기회 공격은 인접 이탈을, 경계사격은 이동 전 현재 위치의 전방 영역·사거리를 검사한다.
3. 이동 반응이 발동하면 해당 step을 우선 취소한다. 취소한 step에는 이동력을 소비하지 않고 남아 있던 예약 경로도 폐기하여 이동 명령 전체를 종료한다. 이전에 완료한 step의 위치·이동력은 되돌리지 않는다.
4. 예약한 반응을 우선권 순서로 처리한다. 실제 공격을 실행하는 유닛은 기본 공격처럼 대상을 향해 Facing을 변경한 뒤 공격한다. 기회 공격 뒤 변경된 방향은 이후 방향 판정에 적용되고, 경계사격 뒤에는 공격한 대상을 향한 방향이 남는다. Facing 변경 뒤 은신 발각 검사는 4.6절과 연결한다.
5. 앞선 반응으로 이동 주체가 사망하면 나머지 예약 반응은 실행하지 않는다. **실제로 실행되지 않은 반응은 소비하지 않는다.** 기회 공격은 해당 대상의 라운드 사용 기록을 남기지 않고, 경계사격은 준비 상태를 유지한다.
6. 반응 처리가 끝난 뒤 이동 주체가 살아 있고 계속 행동할 수 있다면 플레이어의 새 입력을 받는다. 폐기한 경로를 자동 재개하지 않는다.

기회 공격과 경계사격의 실제 반응 공격은 AP를 소비하지 않는다. 경계사격의 준비에 드는 2 AP와 실제 반응 비용을 구분한다. 기회 공격의 사용 기록은 반응 보유자·대상·라운드별이며, 한 보유자가 여러 대상에게 각각 발동해도 총횟수 상한을 두지 않는다.

**강제 이동과 기술 이동에는 두 반응 모두 발동하지 않는다.** 밀치기·끌기·돌진·도약 등 스킬·효과에 따른 위치 변경은 일반 이동과 구분한다. 개척자 Lv5의 기회 공격 방지는 일반 이동에 적용하는 추가 예외이며 경계사격 방지로 확대하지 않는다.

현재 일반 이동과 공격을 위한 접근 경로의 구체 통합, 반응 취소 후 적 AI의 다음 결정, 예약 후 반응자 제거·상태 변경·대상 이동 등 사망 외 무효화 조건과 재검사, 취소된 step의 이동 Facing 처리, 연출·행동 잠금·View 수명 연결은 구현 전에 설계한다. 3.4~3.8절의 현재 실행 흐름에 이 기획이 이미 반영되었다고 해석하지 않는다.

#### 4.11.3. 향후 확인 기준

- 우선권 내림차순으로 라운드를 만들고 동률만 무작위로 정하며 라운드 내 상대 순서를 유지한다. 여러 반응의 동률에도 같은 순서를 쓴다.
- 다칸 일반 이동의 매 step 전에 조건을 검사하고, 반응이 발동한 step은 위치·이동력을 변경하지 않으며 잔여 경로를 폐기한다. 앞서 완료한 step은 유지한다.
- 기회 공격은 인접 이탈 때 AP 없이 발동하고 같은 보유자·대상에 라운드당 최대 한 번만 실행한다. 다른 대상은 별도 발동하며 새 라운드에 기록을 초기화한다.
- 경계 영역 밖에서 안으로 들어오는 step은 경계사격을 유발하지 않고, 영역 안에서 다음 일반 이동을 선언할 때 검사한다. 사거리와 120° 경계 포함을 함께 확인한다.
- 모든 조건 충족 반응을 예약하고 앞선 반응으로 대상이 사망하면 나머지 반응을 실행·소비하지 않는다. 미실행 경계사격과 기회 공격 대상별 사용 가능 상태를 보존한다.
- 강제 이동·기술 이동에는 발동하지 않으며, 실제 반응 공격의 Facing 변경과 그 이후 방향·은신 판정이 연결된다.

위 항목은 구현 후 확인 기준이며 이번 문서 작업의 실행 결과가 아니다.

### 4.12. 기사와 기어스 — 기획 확정·미구현

기사는 데스메리온에게 맹세하여 특별한 힘을 얻은 신규 기본 직업이며 양손 무기를 사용한다. 장비를 바꿔도 직업의 기본 공격 방식과 무기 표현을 유지하는 4.10절의 원칙을 따른다. 양손 무기를 새로운 손별 장비 슬롯 규칙으로 해석하지 않는다.

#### 4.12.1. Lv1 시작 능력

- **패시브:** 이 캐릭터를 강제로 이동시킬 수 없다. 강제 이동 면역과 스스로 사용하는 기술 이동의 분류·실패 처리는 개별 이동 기술과 대조하여 설계한다.
- **강타(가칭):** 양손 무기로 강하게 공격한다. 기본 쿨타임은 3턴이다. 기본 AP 비용을 지불한 뒤 남은 모든 AP를 추가 소모하여 피해를 증가시킨다.
- 강타의 기본 AP 비용, 추가 AP당 피해 증가량, 정확한 피해 공식·사거리·쿨타임 카운트와 갱신 시점은 미정이다. 비용이 확정되기 전에 기본 공격과 같은 2 AP로 간주하지 않는다.

#### 4.12.2. Lv2 기어스와 대응 특성

Lv2에서 기어스와 특성이 일대일로 연결된 쌍 하나를 골라 전문화한다. 선택한 기어스를 위반하면 그 기어스로 얻은 대응 특성을 영구적으로 몰수하며, 기사의 Lv1 기본 능력은 유지한다.

| 기어스 | 지켜야 할 규칙 | 대응 특성 |
|---|---|---|
| 불살의 맹세 | 플레이어의 능동적 선택으로 적을 직접 죽음에 이르게 해서는 안 된다. 반격에 의한 죽음은 위반이 아니며, 플레이어가 선택한 공격에 딸린 처형으로 죽는 것은 위반이다. | 강타 피해 2배 |
| 감시의 맹세 | 특정 방향을 등지지 않는다. | 강타가 기사 자신을 중심으로 사방 2칸 범위 안의 모든 적을 타격 |
| 검소의 맹세 | 장비를 최대 2개까지만 착용한다. | 강타 쿨타임을 1턴으로 줄여 자기 차례마다 한 번 사용 가능 |
| 퇴마의 맹세 | 마법사와 팀을 이룰 수 없다. 전투에 마법사가 있다면 반드시 마법사를 먼저 공격한다. | 강타가 적중한 적에게 침묵 부여 |

검소의 맹세는 일반 최대 3개 장착 규칙에 추가되는 기어스 제약이다. 특성 몰수 뒤 장비 제한의 처리, 맹세 선택 시 이미 장비 3개 또는 마법사 동료가 있는 경우, 위반 가능한 행동의 UI 허용·경고 방식은 미정이다. 선택·제약·몰수의 상태 계약과 영구 몰수의 원정 간 수명은 [MercenarySystem.md](MercenarySystem.md)·[GameState.md](GameState.md)의 후속 설계에서 정한다.

불살 판정은 행위 선택과 사망 원인을 구분해야 한다. 자비 등 선택한 공격의 처형 효과로 죽으면 위반이며, 복수 등 반격에 의한 죽음은 위반이 아니다. 기회 공격·경계사격·지속 피해 등의 원인 분류와 몰수 적용 시점은 별도 설계한다. 감시의 특정 방향을 정하는 방법과 위반 검사 시점은 이동·공격·반응 공격에 따른 Facing 변경 규칙과 대조한다. 퇴마의 마법사 분류·우선 공격 충족 조건, 복수 마법사·공격 불가능 상황, 침묵의 지속 시간·적용 범위는 미정이다.

강타 피해 2배의 계산 위치와 장비·치명타·방어력 관계, 사방 2칸의 정확한 범위·대상별 처리 순서, 쿨타임 3턴/1턴의 카운트, 기어스 위반과 범위 공격의 후속 타격·몰수 순서는 별도 설계한다. 기사의 기본 수치나 Lv3~Lv5 추가 보상을 임의로 정하지 않는다.

구현 후에는 강제 이동 면역, 강타의 기본 비용과 잔여 AP 전부 소비, 기어스 한 쌍 선택·위반 시 대응 특성만 몰수·Lv1 유지, 불살의 반격/선택 공격 처형 구분과 각 대응 특성을 확인한다. 쿨타임·위반·데이터 수명 등 미정 계약을 확정한 뒤 해당 경계를 검증한다. 이는 향후 확인 기준이며 실행 결과가 아니다.

### 4.13. 궁수의 준비 능력과 정령궁수 — 기획 확정·미구현

#### 4.13.1. Lv1 특수화살 제작

궁수의 Lv1 기본 패시브는 전투 외 준비형 능력이다. 전투가 종료되면 전투에서 사용할 수 있는 **특수화살 1개**를 제작한다. 긴 기본 공격 사거리는 직업의 기본 수치·공격 특성으로 유지하며 이 패시브의 효과로 분류하지 않는다. Lv1 액티브 경계사격은 별도 능력이다.

특수화살의 종류·효과·사용 방법·보유 한도·중복 보유, 어느 공격에 적용하는지와 소비 시점, 승리만 제작하는지 패배 등 다른 종료도 포함하는지는 미정이다. 종료 시 제작을 호출하는 책임·용병 상태 조건·결과 적용 순서, 전투 사이의 보관·수명과 아이템/탄약 스키마도 별도 설계한다. 일반 장비의 최대 3개 장착이나 공용 인벤토리 계약에 자동 편입하지 않으며, 정령궁수의 Lv2 정령 부여 능력과 같은 자원으로 합치지 않는다.

#### 4.13.2. 정령궁수 Lv2

궁수 전문화 사냥꾼은 폐기하고 정령의 힘을 화살과 사격에 실어 전장을 간섭하는 **정령궁수** 계열로 교체한다. 정식 명칭은 추후 조정할 수 있다. Lv2·Lv5의 패시브와 액티브는 각 레벨의 고정 보상이며, 다른 궁수 전문화의 효과를 이번 변경으로 추가하거나 변경하지 않는다.

**고정 패시브 — 4속성 기본 공격**

- 기본 공격의 기존 물리 피해를 제거하고 물·불·전기·독 피해를 각각 1씩 가한다.
- 이는 **공격 한 번에 피해 성분 네 개**가 있는 구조다. 네 번의 공격으로 계산하지 않는다.
- 물·불·전기·독 피해에 각 속성 방어력을 개별 적용한다. 각 성분은 `max(0, 1 - 해당 속성 방어력)`이며 다른 방어력을 교차 적용하지 않는다.
- 해당 공격이 치명타가 되면 기존 치명타 추가 피해 +2를 **무속성 피해로 한 번만** 더한다. 네 성분 각각에 +2를 더하지 않는다.

위 수치와 별개로 장비·성장에 따른 공격력·치명타 보너스의 성분별 배분, 한 공격 안의 피해 적용 순서·사망 판정과 공격/피격 효과의 발동 단위는 미정이다. 한 공격이라는 사실을 모든 피해 성분을 물리 피해 하나로 합쳐 방어력을 적용한다는 의미로 해석하지 않는다.

**고정 액티브 — 다음 기본 공격의 정령 선택**

불·물·전기·독 정령 중 하나를 선택하여 다음 기본 공격 1회에 선택한 정령의 특수 효과를 추가한다. 이 효과는 Lv2 패시브의 4속성 기본 공격을 대체하지 않는다.

| 선택한 정령 | 화살 경로의 효과 | 최종 대상의 효과 |
|---|---|---|
| 불 정령 | 불붙은 지면과 연막을 남긴다. | 추가 화염 피해와 화상을 부여한다. |
| 물 정령 | 젖은 지면을 남긴다. | 젖음을 부여한다. |
| 전기 정령 | 경로상의 모든 적에게 전기 피해를 가한다. | 감전을 부여한다. |
| 독 정령 | 독 지면을 남긴다. | 독을 부여한다. |

화살 경로 산정·사거리·장애물, 액티브 AP 비용·실패·취소·준비 유지와 소비 시점, 추가 피해량과 상태이상·환경효과의 지속·중첩·적용 순서는 미정이다. 전기 정령의 경로상 다중 피해가 공격 1회로 취급되는지와 각 대상의 공격/피격 효과 발동 방식은 별도 설계하며 Lv2 패시브의 한 공격·네 성분 규칙만으로 확정하지 않는다. 전기 정령이 전기 지면이나 전기 구름을 직접 생성한다고 추가하지 않는다.

#### 4.13.3. 정령궁수 Lv5

**고정 패시브 — 물리 피해 1회 무효화**

처음으로 받는 물리 피해 1회를 완전히 무효화하고 소모한다. 소모 후에는 착용자 자신의 턴 3회마다 다시 충전한다. 물·불·전기·독·무속성 피해에는 적용하지 않는다. 촛농 갑옷의 모든 속성 피해 1회·자기 턴 5회 규칙과 구분한다.

피해 1회의 단위·0 피해·복수 피해 성분, 수호자 차단·촛농 갑옷 등과 동시에 적용될 때의 순서·소모, 자기 턴 시작/종료 중 충전 시점과 발동한 현재 턴의 포함 여부, 전투 사이의 초기화·충전 상태 보존은 미정이다.

**고정 액티브 — 사용 턴의 무속성 범위 기본 공격**

사용한 턴 동안 자신이 가하는 모든 기본 공격의 피해 속성을 무속성으로 바꾸고, 각 기본 공격이 착탄 지점을 중심으로 범위 1의 모든 적을 공격한다. 그 턴에 기본 공격을 여러 번 하면 매 공격에 적용한다. 범위 1은 착탄 Hex와 인접 Hex를 뜻하는 방향으로 사용하며 아군 피해 여부·장애물·지형 효과 적용 범위는 별도 설계한다.

변경 대상은 기본 공격의 피해 속성이다. Lv2 액티브로 부여한 정령의 경로·상태이상 등 특수 효과는 유지한다. Lv2 패시브의 네 피해 성분을 무속성으로 바꿀 때 합칠지, 성분별로 유지할지, 범위 대상별 치명타·피격 효과와 피해 처리 순서, 비용·실패·취소·턴 종료와 반응 공격의 적용 경계는 미정이다. 불 정령의 추가 피해 등 특수 효과까지 일괄 무속성으로 바꾸지 않는다.

경계사격은 4.9절에 따라 기본 공격의 피해·속성·치명타·방어력과 기본 공격에 적용되는 효과를 따른다. 다음 기본 공격에 준비한 정령의 소비 시점과 Lv5 액티브의 사용 턴 한정 효과를 반응 공격에 연결하는 정확한 경계는 별도 설계한다.

#### 4.13.4. 향후 확인 기준

- 전투 종료 시 특수화살 1개 제작과 긴 사거리·경계사격을 서로 구분한다. 제작 대상 종료·용병 조건·저장 계약을 먼저 정한다.
- 정령궁수의 기본 물리 피해가 제거되고 한 공격의 네 성분에 각각 해당 방어력이 적용된다. 치명타 +2는 무속성으로 한 번만 추가한다.
- 선택한 정령의 다음 기본 공격 특수 효과가 네 성분의 기본 피해에 추가되며 경로와 최종 대상의 효과가 구분된다.
- Lv5 패시브는 물리 피해만 한 번 무효화하고 소모 후 착용자 자기 턴 3회 기준으로 충전한다. 나머지 속성 피해에는 적용하지 않는다.
- Lv5 액티브를 사용한 턴에 기본 공격을 여러 번 수행하면 매번 무속성 범위 공격을 적용하고 Lv2 정령의 특수 효과를 유지한다.

위 항목은 구현 후 확인 기준이며 이번 문서 작업에서 실행한 결과가 아니다. 미정인 피해·충전·준비 소비 경계를 먼저 정한 뒤 검증한다.

### 4.14. 지면·공기 환경효과 — 기획 확정·미구현

정령궁수의 액티브가 불붙은 지면·연막·젖은 지면·독 지면을 직접 요구하므로 환경효과를 전투 기획 범위에 포함한다. 과거 프로토타입에서 타일 원소효과를 제외한 것은 당시 구현 범위이며, 이번 기획의 제외 조건으로 사용하지 않는다. 현재 구현의 지형·점유·이동 규칙이나 기존 프로토타입 문서를 변경 완료했다는 뜻은 아니다.

#### 4.14.1. Hex의 두 슬롯

- 각 Hex에는 **지면 슬롯 1개와 공기 슬롯 1개**가 있다.
- 두 슬롯은 독립적이며 같은 Hex에 지면 상태 1개와 공기 상태 1개가 동시에 존재할 수 있다.
- 각 슬롯은 빈 상태이거나 동시에 하나의 상태만 가진다. 같은 슬롯에 여러 환경 상태를 함께 쌓지 않는다.
- 지면 효과 후보에 **전기가 흐르는 지면**, 공기 효과 후보에 **전기 구름**을 추가한다. 아래 확정 조합에 따른 생성은 적용하며 그 밖의 생성 조건·지속 시간·피해·상태이상·인접 전파는 미정이다.

지면·공기 상태와 캐릭터에게 부여하는 화상·젖음·감전·독은 구분한다. 슬롯 구조만으로 특정 지면의 진입·체류 피해, 시야 차단, 상태이상 부여 또는 지형 이동 비용을 추가하지 않는다. 연막과 아래 반응 결과의 연기가 같은 상태인지도 별도 설계한다.

#### 4.14.2. 반응과 덮어쓰기

새 환경효과가 들어오면 대상 슬롯의 현재 상태와의 관계를 확인하고, 필요한 경우 반대 슬롯의 현재 상태와의 관계도 확인해 결과를 정한다. 결과는 같은 슬롯을 변환·덮어쓰거나 반대 슬롯까지 함께 변경할 수 있다.

아래 다섯 조합은 **적용 순서와 관계없이 같은 결과**를 낸다. 표의 두 상태를 A→B 또는 B→A 순서로 적용해도 동일하다.

| 반응 조합 | 반응 후 지면 슬롯 | 반응 후 공기 슬롯 |
|---|---|---|
| 불붙은 지면 + 젖은 지면 | 빈 상태 | 수증기 |
| 불붙은 지면 + 독 지면 | 불붙은 지면 | 연기 |
| 불붙은 지면 + 전기가 흐르는 지면 | 빈 상태 | 전기 구름 |
| 불붙은 지면 + 독 구름 | 불붙은 지면 | 연기 |
| 젖은 지면 + 전기가 흐르는 지면 | 전기가 흐르는 지면 | 별도 반응이 없으면 기존 상태 유지 |

- 정의한 반응 조합에 해당하지 않으면 새 효과가 **자신의 대상 슬롯**의 기존 상태를 덮어쓴다. 반대 슬롯은 별도 반응이 정의되지 않은 한 유지한다.
- 반응 결과로 반대 슬롯에 새 상태가 생성되면 그 슬롯을 결과 상태로 변경한다. 기존 공기 상태와 수증기·연기·전기 구름을 같은 슬롯에 중복 보관하지 않는다.
- 반응 결과로 생긴 상태를 다시 입력으로 삼아 연쇄 반응을 평가할지는 미정이다. 여러 정의된 조합을 동시에 만족할 때의 우선순위·평가 횟수와 한 공격에서 여러 환경효과를 적용하는 순서도 별도 설계한다.

수증기·연기·독 구름·전기 구름의 개별 효과와 지속·갱신, 동일 상태 재적용, 상태 생성 주체·사망 귀속, 환경효과와 캐릭터 상태이상의 상호작용, 전투 종료·재시작 시 저장·초기화와 실제 슬롯 데이터 형식은 미정이다. 확정 조합을 모든 원소 조합의 상호작용 표로 확대하지 않는다.

#### 4.14.3. 향후 확인 기준

- 한 Hex에서 지면 1개·공기 1개를 동시에 유지하되 한 슬롯 안에는 상태를 둘 이상 두지 않는다.
- 다섯 확정 조합 각각을 두 적용 순서로 비교해 지면·공기 결과가 일치하는지 확인한다.
- 수증기·연기·전기 구름이 결과로 생성되면 기존 공기 상태를 교체한다. 젖은 지면+전기 지면은 별도 반응이 없으면 기존 공기 상태를 유지한다.
- 정의되지 않은 조합은 대상 슬롯을 새 효과로 덮어쓰고 반대 슬롯은 유지한다.
- 미정인 연쇄 반응·복수 조합 우선순위·지속·피해를 임의 동작으로 채우지 않고 필요한 계약을 먼저 확정한다.

위 항목은 향후 검증 기준이며 이번 문서 반영의 실행 결과가 아니다.
