# RaggedBanner 시나리오 프로젝트 안내

이 작업 공간은 RaggedBanner의 이벤트, 스토리와 세계관을 정의하고 발전시키기 위한 문서 프로젝트다. 새로운 세션에서는 아래 핵심 문서를 먼저 읽고, 현재 설정과 시스템 규칙을 파악한 뒤 작업한다.

## 핵심 문서와 읽기 순서

| 순서 | 문서 | 역할 |
| --- | --- | --- |
| 1 | [World_Premise.md](World_Premise.md) | 세계의 기본 전제, 탐험의 정서, 이야기의 범위와 콘텐츠 작성 기준 |
| 2 | [WorldLore.md](WorldLore.md) | 역사·문화·사회적 관습·지식 체계와 장소 설정의 배경 |
| 3 | [plan.md](plan.md) | 게임의 목표, 전투와 성장, 월드맵과 원정 진행, 개발 범위 |
| 4 | [EventSystem.md](EventSystem.md) | 이벤트 데이터 구조, 발생 조건, 결과 처리와 런타임의 책임 |
| 5 | [BlessingSystem.md](BlessingSystem.md) | 신별 고정 축복과 티어, 조건별 원정당 1회 획득, 이벤트 후처리와 미정 사항 |

위 순서는 읽기 순서다. 세계관 설정의 우선순위는 `World_Premise → WorldLore → Lore Anchor → Location / Event`다. 게임의 의도와 범위는 `plan.md`, 이벤트의 상세 계약은 `EventSystem.md`, 축복의 상세 규칙은 `BlessingSystem.md`에서 확인한다. 축복에 관한 다른 문서의 요약은 상세 규칙을 대체하지 않는다.

## 현재 게임과 이야기의 방향

RaggedBanner는 전문 탐험가인 모험가들이 아직 대부분이 알려지지 않은 판타지 세계를 여행하는 탐험 로그라이크다. 기본 감정은 호기심과 발견이며, 플레이어가 “저 너머에는 무엇이 있을까?”를 궁금해하도록 만드는 것이 중요하다.

세계에는 평범한 생활과 자연, 따뜻하거나 우스운 사건, 위험한 괴물과 드문 신비가 함께 존재한다. 서로 독립적인 역사와 전설이 공존하며, 모든 장소와 미스터리를 하나의 고대 문명이나 공통 원인으로 연결하지 않는다.

한 런은 흰밀물이 돌아오기 전까지 목표 장소를 발견하는 한 차례의 원정이다. 플레이어는 고정된 월드맵에서 목표와 이동 경로를 선택하고, 새로운 단서에 따라 목적지를 바꿀 수 있다. 필수 Main Arc 대신 실제로 지나온 장소와 겪은 사건이 원정의 이야기를 만든다.

흰밀물은 먼 곳을 향한 탐험을 중단시키는 세계의 주기다. 그 안에 있는 이는 원래 왔던 길로 되돌아간다. 정확한 귀환 지점과 과정은 미정이며, 세계·기억·기록의 초기화를 전제하지 않는다.

모험가는 직업별 레벨 보상표에 따라 성장한다. 직업별 고정 보상, 직업 내 선택 보상과 직업에 관계없이 선택하는 공용 특성을 함께 사용한다. 기본 구조와 미정 사항은 `plan.md`의 성장 체계를 따른다.

축복은 파티 전체에 적용되는 원정 단위 성장이다. 신별 단계 효과는 고정되어 있으며, 같은 신의 축복을 다시 받으면 티어가 상승한다. 축복·티어·축복 조건 사용 기록은 다음 원정에 초기화한다.

## 이벤트 제작의 기본 구조

- 이벤트는 개발 단계에서 정적으로 제작하며, 런타임에는 LLM이 개입하지 않는다.
- 콘텐츠는 Opening, 선택적 Arc, 독립 사건과 목표 장소의 발견을 다루는 Goal Event로 구성한다.
- 이벤트 사이의 연결은 State·Tags·Arc Stage로 표현한다. 다음 Event ID를 직접 지정하는 고정 체인을 전제로 하지 않는다.
- 생성기는 서사·조건·결과를 만들고, Unity 런타임은 이동·시간·이벤트 선택·원정 종료를 관리한다.
- 원정 시간은 노드 사이 이동에서만 소모한다. 원정 종료는 목표 이벤트 성공, 전투 패배, 시간 소진으로 구분한다.
- 첫 방문에는 이벤트를 보장하며, 재방문은 새로운 진입 경로나 새롭게 충족된 조건에 따라 판정한다. 세부 예외와 처리 순서는 `EventSystem.md`를 따른다.
- 축복과 연결된 이벤트는 태그를 제공하고, 관련 이벤트와 결과 처리가 끝난 뒤 축복 시스템이 미사용 조건을 검사한다. 조건별 원정당 1회 제한은 태그를 지우는 방식이 아니라 별도의 사용 기록으로 관리한다.

## 현재 문서 상태와 작업 시 주의점

`WorldLore.md`는 탐험 지식과 기록 체계, 에다 르윈의 빈칸 지도 전통이 구체화되어 있다. 새로운 항목은 장소·이벤트 생성에 필요한 공통 설정이 확인될 때 추가하며, 미정 목차를 미리 채우는 방식으로 확장하지 않는다.

모험가의 레벨 성장 구조는 정해졌지만, 레벨업 달성 조건과 경험치 사용 여부, 레벨 상한, 실제 보상표·특성 콘텐츠와 원정 간 유지 여부는 미정이다. `plan.md`의 도적 레벨별 보상과 특성 목록은 설명용 예시이며 확정 콘텐츠로 사용하지 않는다.

`plan.md`에는 EventSystem 개편을 예정 작업으로 표현한 부분이 남아 있지만, 현재 `EventSystem.md`에는 목표 공개, 재방문 기록과 종료 처리 순서가 반영되어 있다. 개편 상태는 실제 본문을 확인한다. 문서에 규칙이 정의되어 있다는 사실을 Unity 구현 완료로 해석하지 않는다.

디비니티·발더스 게이트식 전투와 탐험을 결합하는 재기획은 `plan.md`의 기존 전투 관련 절에 아직 반영되지 않았다. 축복과 레벨 성장의 정리를 오토배틀러 전투 방식의 재확정이나 전투 개편 완료로 해석하지 않는다.

총 원정 시간, 목표의 배치·접근 조건, 미공개 목표 선방문, 성공 이후 자유 탐사, 반복 원정 사이의 기록·축복 이외 성장 유지 등은 아직 미정이다. 축복의 원정별 초기화를 세계 전체나 다른 성장의 초기화로 확대하지 않는다.

축복의 동시 발생에서 비선택 조건을 처리하는 방식, 원정 종료와 축복 후처리의 정확한 순서 등은 `BlessingSystem.md`의 미정 사항으로 관리한다. 개별 효과와 티어 수의 논의용 예시를 확정된 콘텐츠로 사용하지 않는다.

이 안내는 프로젝트의 진입점이다. 구체적인 작업에서는 관련 핵심 문서의 최신 본문과 `AGENTS.md`를 함께 확인한다.
