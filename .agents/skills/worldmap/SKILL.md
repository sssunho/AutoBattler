# Worldmap

## 기준 파일

- 최신 편집 원본: `C:\Users\Doggie\Desktop\Resume\RaggedBanner\Art\WorldMap\worldmap.map`
- 지도 백업 폴더: `C:\Users\Doggie\Desktop\Resume\RaggedBanner\Art\WorldMap\worldmap_bak`
- Unity 임포트 대상: `C:\Users\Doggie\Desktop\Resume\RaggedBanner\Assets\Art\UI\WorldMap\WorldMap.png`
- Unity 임포트 설정: `C:\Users\Doggie\Desktop\Resume\RaggedBanner\Assets\Art\UI\WorldMap\WorldMap.png.meta`

항상 `worldmap.map`을 최신 원본으로 읽고 지도 수정 요청을 이 파일에 반영한다. 이전 이름의 지도, 백업, 임시 파일을 최신 원본으로 취급하지 않는다. 원본이 없으면 임의로 다른 지도를 선택하지 말고 사용자에게 알린다.

## 요청 구분

- 지도 수정 요청이면 `.map`을 수정한다. Unity PNG까지 자동으로 교체하지 않는다.
- 임포트 요청이면 최신 `.map`을 읽어 아래 8K 임포트 절차를 수행한다. 임포트만으로 `.map`을 변경하거나 지도 백업을 만들지 않는다.
- 수정과 임포트를 함께 요청하면 `.map` 수정 완료 후 그 결과를 임포트한다.
- 조회·설명·설계만 요청하면 지도와 PNG를 변경하거나 백업하지 않는다.

## 지도 수정과 백업

1. 원본을 수정하기 직전에 현재 `worldmap.map`을 백업한다. 백업 폴더가 없으면 생성한다.
2. 로컬 날짜·시간을 사용해 `worldmap_bak\_yyyyMMdd_HHmmss_fff.map`으로 복사한다. 예: `_20261025_153045_123.map`. 기존 백업을 덮어쓰지 않는다. 이름이 겹치면 새로운 시간 이름을 만든다.
3. 백업이 현재 원본과 바이트 단위로 같은지 또는 SHA-256이 같은지 검증한다. 백업 생성이나 검증에 실패하면 원본을 수정하지 않는다.
4. 백업 폴더 바로 아래에서 위 날짜시간 형식에 해당하는 `.map` 파일만 관리한다. 파일명의 날짜시간으로 정렬하고 최신 3개만 남기도록 가장 오래된 파일부터 제거한다. 3개 미만이면 개수를 채우려고 중복 백업하지 않는다.
5. 삭제 대상의 실제 절대 경로가 지정한 백업 폴더 바로 아래인지 확인한다. 다른 폴더, 다른 이름의 파일, 하위 폴더는 정리 대상에 포함하지 않는다.
6. 백업 생성·검증·정리를 마친 뒤 요청한 변경을 `worldmap.map`에 반영한다. 해안·높이·스타일·기존 요소 등 요청과 관련 없는 데이터는 보존한다.
7. 직접 텍스트를 수정할 때는 현재 `.map`의 저장 형식과 참조 관계를 확인한다. SVG 표시만 바꾸지 말고 해당 강·심볼·경로 데이터도 일치시킨다. 가능한 환경에서는 편집기로 다시 불러와 표시와 편집 가능 여부를 확인한다.

## 8K Unity 임포트

1. 최신 `worldmap.map`의 현재 지형·스타일·표시 레이어·사용자 지정 심볼을 반영하여 전체 지도를 렌더링한다. 이전에 만든 SVG나 PNG는 최신 원본과 일치하는지 확인되지 않으면 재사용하지 않는다.
2. 출력 크기는 **8K UHD인 7680×4320 픽셀**이다. 작은 지역만 잘라내거나 저해상도 PNG를 단순 확대하지 않고, 지도 전체의 원본 벡터·데이터를 이 해상도로 렌더링한다.
3. 임시 PNG의 해상도와 정상 디코딩을 검증하고 미리보기에서 최신 배치를 확인한 후 지정한 `WorldMap.png`를 교체한다.
4. 기존 `.meta`를 보존하면서 필요한 임포트 설정만 맞춘다.
   - 기본 최대 텍스처 크기는 **8192**로 설정한다. 활성 플랫폼 오버라이드 때문에 8K가 축소되지 않는지 확인한다.
   - 기존 텍스처 GUID, 스프라이트 ID/fileID, 이름, 모드, 피벗과 참조를 유지한다.
   - 전체 지도 스프라이트의 잘라내기 영역을 **7680×4320**으로 유지한다.
   - 현재 **Pixels Per Unit 50**을 유지한다. 지도 UI가 `SetNativeSize()`를 사용하므로 반복 임포트 때 PPU를 다시 절반으로 낮추지 않는다. 해상도를 바꾸는 별도 요청이 있다면 기존 표시 크기를 보존하도록 계산한다.
5. Unity가 실행 중이고 에셋 임포트 도구를 사용할 수 있으면 해당 텍스처의 재임포트 결과를 확인한다. Unity를 사용할 수 없으면 파일과 설정 검증 결과를 보고하고, 에디터에서 재임포트까지 확인했다고 표현하지 않는다.

## 결과 보고

수정한 파일, 수행한 검증과 남은 확인 사항을 간단히 보고한다. 지도 수정 시에는 생성한 백업과 남긴 백업 개수, 임포트 시에는 실제 PNG 해상도와 Unity 임포트 확인 여부를 포함한다.
