# Character Texture Cleanup

기존 캐릭터의 디자인과 재질 구분을 유지하면서 요청한 텍스처 후처리를 수행한다. 실제 파일과 모델 적용 화면을 근거로 작업하고 한국어로 보고한다.

## 범위와 권한

- 현재 사용자의 지시와 적용되는 `AGENTS.md`를 따른다. 분석·진단은 읽기 전용이며, 필요한 설계 승인은 프로젝트 지침에 따른다. 변경 전 대상, 결과 경로, 보존 요소와 검증 방법을 정리하되 같은 작업에서 이미 받은 설계 승인이나 도구 사용 허용을 다시 요청하지 않는다.
- 요청한 음영·하이라이트·붓결 정리 또는 단색화에 집중한다. 모델 재디자인, 메시·토폴로지·리깅·UV 변경, 애니메이션 제작은 별도 요청 범위다.
- Unity Scene, GameObject, Component, 셰이더, 머티리얼과 임포터 설정을 요청 없이 변경하지 않는다. Unity 컴파일·빌드와 이를 유발하는 검증은 명시적으로 허용된 경우에만 수행한다.
- 현재 사용할 수 있는 도구와 권한을 확인한다. 같은 Blender 문서를 다른 작업자와 동시에 수정하지 않는다.

## 대상과 기준 상태 확인

- 현재 프로젝트 루트에서 파일 경로를 해석한다. 사용 가능한 Blender MCP와 연결 상태를 확인하고, 연결된 경우 실제 장면과 선택 오브젝트를 조회한다. 연결되지 않으면 로컬 파일로 가능한 검사를 진행하며 열린 장면을 확인했다고 보고하지 않는다.
- 메시 이름, 정점·면 수, 크기·변환, Armature, 재질의 이미지 연결, 이미지 경로·해상도와 UV 레이어를 확인한다. 활성 오브젝트나 파일 이름만으로 다른 캐릭터와 같은 대상으로 판단하지 않는다.
- 원본 텍스처, 실제 모델 적용 상태와 사용자 참고 화면을 직접 확인한다. 텍스처에 구워진 명암과 실시간 조명, 노멀·형상에서 생긴 명암을 구분한다.
- 변경 전 원본 파일과 이미지 크기·알파, 메시 좌표·토폴로지·UV·변환 및 기존 재질 연결의 기준 상태를 기록한다. 기존 미저장 작업을 버리거나 열린 Blender 문서를 임의로 교체하지 않는다.

## 후처리

- 요청에 맞춰 구워진 그림자·하이라이트·잔음영을 제거하거나 완화한다. 붓결 제거와 단색화는 요청된 경우에만 적용한다. 금속·가죽·천·피부의 기본색과 디자인 구분을 유지한다.
- 재질 부위와 UV 영역에 맞게 처리한다. 전체 이미지에 동일한 블러·밝기 조정·노이즈를 적용하는 것만으로 해결하지 않으며, 조명을 제거하면서 특정 방향의 강한 그림자나 하이라이트를 새로 굽지 않는다.
- 얼굴과 머리는 기본적으로 보호한다. 눈·입·눈썹의 선명함과 인상을 유지하고, 얼굴 변경 요청이 있으면 승인된 범위만 수정한다.
- 원본 해상도, UV 배치, 알파 유무와 필요한 경계 패딩을 보존한다. UV가 다른 캐릭터의 텍스처나 마스크를 그대로 재사용하지 않는다.
- 현재 세션의 이미지 생성·편집 도구 정책과 사용자 허용 범위를 따른다. Python 이미지 편집을 명시적으로 허용받은 작업에서만 마스크·팔레트·합성 등의 결정적인 후처리에 내장 Python 환경을 사용한다. 과거 작업의 허용을 새 작업의 포괄적 허용으로 해석하지 않는다.
- 런타임이 필요하면 제공되는 workspace dependency 도구로 내장 환경을 확인한다. 필요성이 확인되지 않은 Python·패키지·애드온 설치를 먼저 요구하지 않는다.
- 결과의 해상도나 UV 정렬이 원본과 다르면 그대로 완성본으로 저장하지 않는다. 허용된 방법으로 바로잡은 뒤 수치와 시각 검사를 모두 수행한다.

## 저장과 검증

- 사용자 지정 결과 경로를 우선한다. 미지정 시 용도를 구분할 수 있는 별도 파일을 제안한다. 원본 모델·텍스처와 기존 결과는 보존하며, 사용자가 덮어쓰기를 승인했다면 대상과 백업을 확인한 뒤 적용한다.
- 결과를 복제 모델 또는 임시 재질에 적용해 UV 이음새·색 번짐·얼굴 손상을 확인한다. 검증을 위해 만든 일시적인 연결·재질 변경은 복원하거나 별도 검토 파일에 격리한다. 이를 Unity 머티리얼·Scene 변경 허용으로 해석하지 않는다.
- 같은 Blender 카메라·조명·노출에서 원본과 수정본의 근접 및 게임 거리 비교 이미지를 만들고 직접 확인한다. 정리 대상 명암과 재질색 구분이 어떻게 바뀌었는지, 얼굴의 선명함과 인상이 유지되는지 검사한다.
- 저장된 결과의 해상도·알파·UV 대응과 실제 이미지 연결을 확인하고, 보호 대상으로 정한 메시·UV·변환·리그에 의도하지 않은 변경이 없는지 비교한다. 수치 검사만으로 시각 품질을 통과 처리하지 않는다.
- Unity 접근이 가능하고 해당 작업이 승인된 경우에만 실제 Unity 비교를 수행한다. Blender 확인만으로 Unity 화풍·재질 표시나 Humanoid 호환성을 검증했다고 보고하지 않는다.
- 완료 보고에 결과 파일 링크, 주요 변경, 실제 수행한 검사와 남은 문제를 적는다. 수치·시각 검사 및 Blender·Unity 검증을 구분하고, 도구 연결이나 실행 권한 때문에 확인하지 못한 항목도 명시한다.
